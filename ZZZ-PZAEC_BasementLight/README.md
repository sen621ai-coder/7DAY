# 地下工坊柔光吸顶灯 1.0.10

设计覆盖 **12×12 格**，建议层高 **5～6 格**。灯盘0.92×0.92格、厚约0.16格，占一个方块，原生供电 **15W**。

## 安装与使用

房主及所有玩家更新完整 ZZZ-PZAEC_BasementLight 文件夹并彻底重启游戏。已有灯具重新加载后使用新配光，无需重开存档。

工作台搜索「地下工坊柔光吸顶灯」：锻铁6、电气零件8、废聚合物10、碎玻璃8。安装在房间中央天花板下，对准方形面板接线，开启原生开关。长按交互可回收。库存仍使用原版长条灯图标。

## 当前照明

- 主灯强度1.45、衰减范围20格，色温约4500K（RGB 1, 0.87, 0.73），平滑向下配光，抑制中心热点。范围是衰减余量，不代表20格半径内均匀照明。强度已按暖色降亮补偿。
- 墙顶补光强度0.41、衰减范围14格，色温约4800K（RGB 1, 0.90, 0.78），位于灯具下方约1格处，近似模拟反射；主暖补冷保持约300K层差。朝侧上方出光、平滑过渡，压低正上方亮斑，正下方不额外泛光。
- 两个光源均保留柔和阴影，不修改全局环境亮度、曝光或其他灯具。补光不是真实全局光照；游戏关闭阴影时不能保证隔墙遮挡。
- 灯罩通电开启后呈暖乳白亮面（RGB 0.85, 0.82, 0.74），与暖色光一致；关闭或断电恢复灰白。两层光源同步开关，保留原生电网与存档功能。无图形服务器不创建渲染光源。

## 验证

Build.ps1 使用本机游戏程序集编译；Test.ps1 检查12×12理论配光、补光连续性及亮度上限、配置和原生模型/接线接口；Test-Lifecycle.ps1 在模拟Unity场景执行实际源代码，验证碰撞归属、锚点、材质和两层光源开关及回收。

理论检查中，灯面离地4.8～6.0格时，主灯地面最亮/最暗比约1.49～1.62。这不是游戏渲染测量，不包含实际阴影、曝光、材质和补光。尚需实机确认最终效果。大型货架与墙体会形成遮挡，分隔房间需独立布灯。

历史：1.0.3修复配方；1.0.4独立模型与接线；1.0.5降低过曝；1.0.6灯罩状态反馈；1.0.7缩至12×12并增加弱墙顶补光。1.0.8依据偏暗反馈适配5～6格层高，提高主灯衰减余量及墙顶补光，并适度放松中心抑制。1.0.9提亮：主灯1.0→1.2、补光0.14→0.35。1.0.10整体转暖：主灯≈4500K、补光≈4800K并同步灯罩暖色，强度按暖色降亮补偿至1.45/0.41。preview.png仅为灯盘外观示意。
