# 地下工坊柔光吸顶灯

## 1.0.4 模型与接线修复

改用独立模型和独立对象池，安装预览与世界实例共用同一块方形灯盘，不再叠加原版荧光灯模型。碰撞体放在灯具根节点，并显式绑定方块根引用；新增原生 `WireOffset` 接线锚点。保留着色器辅助贴图，使用不透明白色底图；对象回收前解绑共享材质，避免拆除一个灯后其他灯或预览失去材质。

房主及所有玩家完整更新本文件夹后重启游戏，DLL 和 Config/blocks.xml 必须配套，客户端单独更新无法覆盖房主下发的旧模型配置。既有灯具在区块重新加载时使用新模型，不需要改存档；若仍有旧实例，原生回收后重新放置。准星对着方形面板接线。

已通过游戏程序集编译、原生模型入口/命中根引用/接线锚点契约检查、33 项模拟场景生命周期检查和原有 18×18 配光计算。模拟检查包含碰撞体归属、预览结构、材质贴图、开关状态、对象复用和无图形服务器；不代表已完成实际游戏接线及渲染验收。

验证脚本：`tools/BasementLight/Test.ps1`、`tools/BasementLight/Test-Lifecycle.ps1`。

独立模组，名称 `pzaecBasementPanelLight`。实体灯盘 0.92×0.92 格、厚约 0.16 格，占一个方块，原生供电 15W。深灰金属边框、乳白面板，中性偏暖白光。

## 使用

完整退出游戏后重新启动加载 DLL。联机服务器和所有客户端都安装本文件夹，使用与现有代码模组相同的启动方式。

工作台搜索「地下工坊柔光吸顶灯」，用锻铁6、电气零件8、废聚合物10、碎玻璃8制作。创造模式同名搜索；测试控制台可用 `giveself pzaecBasementPanelLight 1`。

将灯贴在18×18格房间中央的天花板下，推荐层高4～5格，接入至少有15W余量的电网，并开启灯具开关。长按交互使用原生回收功能。库存图标暂用原生长条灯图标；放置后显示定制方形灯盘。

## 光照

单个带柔和阴影的点光源和立方体配光纹理，压低正下方光量、补偿斜向光量，避免依靠整体加亮制造中心白斑。无闪烁、无动画、无额外隐藏灯阵列。光源22格的截断距离用于衰减余量，配光目标仍为18×18格地面，不代表22格半径内均匀照明。

配光按4.2格灯面至地面距离计算；4～5格层高做了理论覆盖检查。检查覆盖灯面离地3.8～5.0格（包含贴顶灯体占用的高度余量），理论最亮/最暗比约1.31～1.75（含纹理量化），**不是游戏截图测量值**。游戏的着色器、亮度、曝光和阴影质量会影响实际结果；墙体、货架会形成遮挡，分隔房间需各自布灯。

尚未实机验证：地下室中心及四角亮度、低画质阴影、联机开关同步、区块重载和拾取。请保留阴影以减少隔墙漏光；未完成这些实测前不承诺所有画质下的均匀度。

运行时复用游戏自带材质并生成简洁几何，不依赖额外Unity资源包。仅定制本灯，其他灯具不变。原生电网、开关和存档承载功能状态。`preview.png` 是尺寸一致的离线外观示意，不是游戏内照明验收图。

## 1.0.3 工作台修复
