# MD-500 本地兼容补丁

保留现有汉化、100 万耐久和速度适配，飞控由 `99-AEC_T16_RuntimeFix` 提供。

当前环境防护由共享模块 `ZZZ-PZAEC_SealedCabins` 提供，与阿帕奇、M1 使用相同规则：

- 所有实际乘坐的驾驶员和乘客隔绝环境辐射、炎热与寒冷，停车、熄火、缺油仍有效。
- 不清空上机前已有累计辐射，中暑、冻伤按原本脱离恶劣环境后的规则逐渐恢复。
- 下机、飞机摧毁或换乘不支持的载具后恢复正常环境判定；飞机旁边和机顶没有防护光环。
- 保留疾病、药物反作用和怪物直接攻击的规则。

MD-500 原有 `buffVehicleArmor*` 只修改载具自损，不提供环境隔绝。服务器和客户端须同时保留共享模块完整目录，并重启后生效。具体范围和实机验收项目见共享模块 README。
