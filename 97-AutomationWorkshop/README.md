# 自动化工厂 0.7.1

七日杀 V3.2 的独立自动化 Mod。服务器和所有客户端安装同一整个文件夹，依赖现有 Harmony，关闭 EAC。最新验证记录见 PLAN.md。

## 普通材料直接锻造与配方显示

制作锻钢：自动锻造机选择“锻钢”，上3行放普通铁、黏土块、坩埚，下3行留空。无需先制造自动化冶炼料。选择产品后点击保存并关闭库存后生产。中间独立的“配方与材料”检查窗口已移除，腾出界面空间。

普通铁、黏土、铅、黄铜、石头、碎玻璃按原生熔炼重量折算；旧自动化冶炼料优先抵用，已有流水线继续可用。直接使用普通材料会计入熔炼时间。整件原料折算后若有余量，以原有冶炼料返还原料区，不吞余料；无空间返还时暂停且不扣料。厨房也使用同一材料需求面板。

## 内置库存与原生面板

长按交互键选择“配置机器”，或打开机器库存，即进入同一个原生 XUi 面板：左侧搜索/翻页选择产品、启停和库存模式；右侧为原生物品格，并显示玩家背包。选择后点击“保存”，关闭不会保存未提交的配置。厨房和锻造的实际生产仍按服务端配方计算材料和工具需求。

- 厨房、冶炼、锻造、分解、农场、矿机、分拣机、输送器、水泵和供弹器均自带36格库存：**上3行18格原料/工具，下3行18格成品**。为防混区，机器库存不提供整箱排序。
- 新放设备默认内置模式。旧存档设备保留外接箱模式；在面板点击“库存”切换为内置，然后保存即可，不必拆设备。切换模式不搬动物品，旧箱子和机器内物品各自保留。
- 生产设备先选产品，将材料/工具放上3行；成品进入下3行，**不需要样品或额外输入输出箱**。满仓不扣料、不继续进度。打开库存时暂停加工和运输，关闭后恢复。
- **传送带出口指向机器→送入原料；传送带入口贴机器、箭头背向机器→取走成品。**机器无固定输入面/输出面，以传送带方向区分。继续要求同主人、同区块及已供电的传送带网络。外接箱模式不接入机器内置库存。
- 分拣机按所选物品把原料转入成品，未选则全部通过；输送器不筛选，每次最多16件。
- 矿机上3行放钻头耗材；农场上3行放种子，可放灌溉水加速。仍检查真实矿点、成熟作物和自有领地。
- 水泵紧贴水体，灌溉水进入内置成品区（最多200份），传送带直接取水；供弹器上3行放匹配弹药，紧邻同主炮塔，实际射击时扣弹。
- 外接箱模式保留旧逻辑：输入相邻、输出4米内、同主人同区块、输出首格样品保留。分解保护仍拒绝品质6、带模组、Meta>0及锁定格装备。

库存、所有者与进度由原生区块存档保存。V18旧设备读取新增功能时建立空库存并保留旧模式；不修改旧进度字段格式。配置保存在世界目录 `automation-machine-settings.xml`，原子保存并保留 `.bak`，备份世界时一并保留。配置服务端核验所有者/明确授权、距离、版本及会话，物品操作复用原生容器锁和同步；当前持锁玩家可以保存配置，其他玩家不能越过锁。

原自动化制造工作台继续使用原生工作台面板。电线实现沿用0.6.1，此次未修改。

## 0.6.1 电线常显

普通电线默认常显，收起接线工具后也能看见。仍使用原生线条，接线工具的电流脉冲提示保持原规则；拆线与区块卸载仍正常隐藏并回收线条。退出游戏再启动后生效，不需要重新接线。此改动不调整接线数量上限，也不修改存档电路；尚未加载的端点或缺失端点不会凭空生成电线。

## 0.5.2 模型交互修复

修复新机器和传送带能看见却无法被游戏当作可交互方块的问题。模型实例绑定原生 TileEntity 时，为碰撞体补上 `T_Block` 标签、原版第 16 层 TerrainCollision 碰撞层和 `RootTransformRefParent`，使游戏的 `Voxel.Raycast` 能定位所属方块。已有模型资源包可继续使用，退出游戏并更新 DLL 后重载生效，无需拆除旧设备。

生产设备仍从旁边的输入/输出箱取放材料，本体使用原生交互菜单和状态提示；储水罐及传送带使用原生库存。服务器和所有客户端都需要更新。图形客户端实际按键操作仍需现场验收，不能用单纯的 Unity 碰撞测试代替。

回归验证：16 种模型均先复现未绑定时的原生选取失败，再通过实际 TileEntity 绑定钩子修复；四个方向的 Voxel 射线、正确方块 ID、原生提示、编辑或库存命令全部通过。测试独立服务器仅模拟本地身份和按键标签，权限判断及命令逻辑仍用原生代码；1953 项库存与生产检查通过。

## 0.5.1 独立机器外观

11 种原钢箱设备改为原创简模：分拣扫描架、双灶厨房、熔炼炉、锻压机、双滚轮分解机、灌溉种植架、立式钻机、转运机械臂、水泵、圆筒储水罐和弹药供给器。输入/输出箱仍为原版钢箱，工作台和供电接口仍用原版模型。

保留方块 ID、配方、单格占地及原生 TileEntity 特征顺序，旧设备重载后使用新外观。每台机器使用单一碰撞体，避免小零件影响选取。原有文字牌状态改在瞄准提示中显示，仍沿用原生存档和网络数据。机器外观为静态模型，机械动作和运行特效尚未加入；传送带货箱继续移动。

构建：先运行原有配置生成脚本，再运行 `tools/EscortNPC/generate_automation_machines.py`；`tools/Build-MachineAssets.ps1 -Preview` 生成并验证资源包与 Unity 预览图。将 `automation-machines.unity3d` 放入本 Mod 的 Resources 目录。服务器与客户端均须更新整个 Mod 文件夹。

验证：Unity 资源包重载、11 台机器单格模型边界和材质检查；真实无界面游戏内加载全部模型、正面射线选取、状态提示、原生存档与网络序列化；32 个工作台配方与传送带完整回归均通过。1953 项库存/生产检查使用当前安装 DLL 重新编译执行。尚未完成图形客户端操作和双客户端现场验收。

## 0.5.0 可见传送带

新增直线、左转、右转、上坡、下坡五种传送带，全部在自动化工作台制作。使用独立机械模型、黄色方向标记和移动货箱，不是原先的箱间输送器。货箱表示一批货物；按 E 打开原生库存查看实际物品和数量，瞄准时显示运行状态。

- 后端接自动化输入箱或输出箱，按黄色标记逐段连接，末端接输入箱或输出箱。输出箱首格仍是过滤样品，取料与入料均保留样品。
- 每秒最多前进一段，每次最多16件；每段有一个原生库存槽，物品保留品质、耐久和模组数据。
- 同一所有者、同一16×16地图区块内的连通线路，任意一段邻接通电的供电接口即可运行。每条线路最多32段，接口按原有10W耗电；开箱、缺电、满箱、方向不合均暂停。
- 坡道末端连接高一格或低一格的下一段。高处仍需按原版建筑规则提供支撑。
- 拆除前先取出带上的货物；破坏设备沿用原生容器规则。跨区块运输及分流器未实现。
- 服务器处理实际库存搬运，客户端只显示同步的货箱。使用原生 TileEntity 库存/状态同步与存档，不用真实掉落物模拟货流，也不补算离线运输。

## 外接箱模式的摆放与流水线

1. 输入箱紧贴机器任意一面；供电接口也紧贴机器，用接线工具连上电源。
2. 输出箱位于机器水平4米、上下1米内。第一格放成品样品，其余格收产物。
3. 输入、输出和机器由同一玩家放置，且在同一个16×16水平地图区块内。队友按原生箱子权限取放物品。
4. 关闭箱子和标签编辑界面后开始工作。锁定格不消耗或填充。
5. 生产机也能取相邻输出箱的产物，保留其首格样品。每次配方材料须能在一个输入容器中凑齐。
6. 合并多个上游产物时，在输出箱和下游输入箱之间放输送器，将不同材料送入公共输入箱。

例：原料输入箱→冶炼机→铁冶炼料输出箱→输送器→锻造输入箱。将黏土冶炼料也送入锻造输入箱，并放入所需工具。锻造输出箱首格放锻铁或锻钢样品。

## 生产规则

- 食品和锻造检查机器所有者在线、配方解锁、工具及材料，使用原版配方效果与沙盒倍率。仅生产无品质产物，暂不自动制造武器护甲。
- 材料完工时扣除并发放产物。缺电、缺料或满箱暂停，换生产任务重置进度。进度随机器区块保存，客户端不能提交进度。
- 六类冶炼料为铁、黄铜、铅、玻璃、石和黏土，每件对应1炉内单位。首个样品可用1份原料在自动化工作台制作，批量应使用冶炼机按原版重量产出。关闭原版冶炼系统时锻造使用原版实物材料配方。
- 分解机只处理有品质装备，跳过六品质及以上、带模组、装有弹药和锁定格。不会自动拆模组。无法原版分解的整合包装备也不会被分解。
- 农场扫描周围7×7、上下1米，限同区块、自己领地石保护区、原版成熟玩家作物。先手动播种，原料区或外接输入箱补种子。只给基础收获，不给玩家技能额外收获或返种；不处理野生、未成熟或邻居作物。
- 矿机检测下方1–8米、周围7×7，限同区块和自有领地。支持铁、铅、煤、硝石、油页岩。**矿点持续产出，矿块不会被挖掉或耗尽。** 所有者须在线；1钻头耗材需1锻铁+1机械零件。
- 所有设备仅在区域已加载时工作，无离线补产。服务器每秒轮询最多32台，更多机器按轮次处理，生产会变慢。

## 外接箱模式的供水与炮塔接法

- 抽水泵紧贴水体与通电供电接口；储水箱放在水平4米、上下1米内。水泵不需要输入箱或样品，每5秒供水1份，上限200份；不耗尽水体，也不产饮用水。
- 农场附近同样放储水箱。有水消耗1份，将每株收割补种从10秒缩短到5秒；缺水仍按10秒作业，不改变植物的原版生长周期。抽水泵与农场可共用同一储水箱。
- 外接供弹器紧贴炮塔、弹药输入箱及供电接口。炮塔自身也要通电。所有设备和箱子同一所有者、同一区块；兼容的原版弹种由炮塔自身定义。
- 有电、有弹时，供弹器会自动启用炮塔。射击优先消耗炮塔内置弹药，耗尽后从外接箱每次扣1发，不预先搬入炮塔弹仓。支持输出箱供弹并保留首格样品。
- 箱子打开、槽位锁定或炮塔正在操作时，外接供弹暂停。关闭供弹器电源可停用外接供弹，炮塔内已有弹药仍由原版管理。
- 原版炮塔弹药面板只显示内置弹仓；外接库存看弹药箱。此次适配以服务端自动射击为目标，客户端手动瞄准射击仍使用原版内置弹仓。
- 原版瞄准、阵营选择、敌我设置、射速、伤害均未改动。仍需游戏内验证联机射击和缺弹恢复。
