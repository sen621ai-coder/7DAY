# 自动化专用页面 0.8.1（已安装）

0.8.1 恢复原生电线显示规则：手持接线工具时显示，收起后隐藏；电路连接和供电逻辑不变。需重启游戏后验证实际画面。

只用于自动化设备，按用户提供的布局设计。普通箱子、背包和原版工作台的布局保持不变。

- 左侧搜索并点击成品；中间显示成品图标、材料/工具及“已有 / 需要”。红色数量表示不足。
- 右上18格放材料与工具；右下18格自动收成品。两边的存入、整理、取出按钮只操作自己的区域，锁定格保留。
- 点击保存应用产品和库存模式；启动/暂停按钮同时保存当前设置。关闭页面后机器才继续加工。
- 内置模式可直接接传送带：送入材料区，从成品区取出。外接模式从指定外箱加工，不使用内置库存。
- 原生背包保留。机器页面的背包快捷存入默认进入材料区，不因材料区满而混入成品区。
- 自动厨房/锻造的材料信息从实际生产计划读取，普通铁和黏土可直接使用；工具不消耗。
