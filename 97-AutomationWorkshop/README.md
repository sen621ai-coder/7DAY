# 自动化工厂 0.9.4

已于2026-09-21安装0.9.4：四格范围供电、装备自动识别拆解、传送带输出箱无需样品收货、普通材料跨批次堆叠。文件校验和配置检查通过；实际游戏流程仍待验收。


新增“自动制作工作台”（`yfAutoWorkbench`），在原来的自动化设备制造工作台中制作，需要自动化机架×3、控制器×2、电机×2。

- 支持普通工作台及手工配方中的无品质产物，包括火药、9mm／7.62mm 子弹、霰弹和零件；不支持化学工作站专属配方或有品质武器装备。
- 在半径4格内放置供电接口并接通电源，打开设备后选择产品、保存并关闭页面。上18格放材料和工具，下18格自动收成品；工具不消耗。
- 默认内置库存，传送带可直接送入材料并取走成品；也可以切换为外接箱模式。
- 沿用设备所有者的配方解锁、材料消耗、产量和制作时间加成。所有者在线且区块已加载才生产；缺电、缺料、满箱、暂停或正在打开库存时停止加工。

弹药流水线示例：

```text
煤 + 硝石 → 自动制作工作台（火药）→ 传送带
                                           ↓
弹头 + 弹壳 → 自动制作工作台（9mm 子弹）→ 成品箱
```

第二台的材料区先补入弹头、弹壳，火药由第一台传送带持续供应。弹头、弹壳也可分别由自动锻造机生产。所有传送带和对应设备应在同一区块内。

本次新增设备，不改已有机器或原版工作台的库存布局，也不修改玩家存档。安装后重启游戏；联机双方均需更新。

## 自动化学合成台

新增 yfAutoChemistry（自动化学合成台），在自动化工作台中制作：自动化机架×3、控制器×2、自动化水泵×2、烧杯×1。

- 只使用化学工作站的无品质配方，例如火药、胶水、染料、汽油。未解锁配方不会生产；材料、产量和时间按设备所有者的实际技能计算。
- 半径4格内放置通电供电接口，选择产品并保存，上18格放材料及工具，下18格收成品；关闭库存后运行。
- 默认内置模式，支持传送带进出料，也可切换外接箱模式。沿用现有所有者、区块和停机规则。
- 示例：煤＋硝石 → 自动化学合成台（火药）→ 自动制作工作台（加入弹头和弹壳制作子弹）。化学和手工配方保持各自的材料比例。
- 胶水、染料等配方要求的瓶装净水不能用灌溉水替代。
- 使用现有紧凑加工设备模型及化学工作站图标，不替换原版化学工作站。

## T 字合流传送带

新增 `yfAutoBeltMerge`，在自动化工作台使用输送组件×1、锻铁×2、机械零件×1制作。左右两个入口合并到箭头指向的前方出口，后方封闭；旋转方块可改变朝向。可接普通传送带、自动化输入／输出箱和内置模式机器（只提取机器成品区）。

两侧都有货时按批次交替取料；一侧缺货时继续使用另一侧。单批最多16件，上一批未排空时停止进料，出口堵塞或断电不会丢弃货物。沿用同所有者、同区块、连通线路最多32段和供电接口范围规则。

四种材料可先两两合流，再用第三个 T 字合流带汇总后送入机器。合流按批次轮流，不按配方比例定量；仍需控制上游供给，避免材料区被过量材料占满。存档保留带内货物，重载后从左侧优先重新开始轮询。
