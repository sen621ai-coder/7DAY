# 自动化工厂 0.9.4

已于2026-09-21安装0.9.4：四格范围供电、装备自动识别拆解、传送带输出箱无需样品收货、普通材料跨批次堆叠。文件校验和配置检查通过；实际游戏流程仍待验收。


新增“自动制作工作台”（`yfAutoWorkbench`），在原来的自动化设备制造工作台中制作，需要自动化机架×3、控制器×2、电机×2。

- 支持普通工作台及手工配方中的无品质产物，包括火药、9mm／7.62mm 子弹、霰弹和零件；不支持化学工作站专属配方或有品质武器装备。
- 在半径4格内放置供电接口并接通电源，打开设备后选择产品、保存并关闭页面。上18格放材料和工具，下18格自动收成品；工具不消耗。
- 默认内置库存，传送带可直接送入材料并取走成品；也可以切换为外接箱模式。
- 沿用设备所有者的配方解锁、材料消耗、产量和制作时间加成。所有者在线且区块已加载才生产；缺电、缺料、满箱、暂停或正在打开库存时停止加工。

弹药流水线示例：

```text
煤 + 硝石 → 自动制作工作台（火药）→ 传送带
                                           ↓
弹头 + 弹壳 → 自动制作工作台（9mm 子弹）→ 成品箱
```

第二台的材料区先补入弹头、弹壳，火药由第一台传送带持续供应。弹头、弹壳也可分别由自动锻造机生产。所有传送带和对应设备应在同一区块内。

本次新增设备，不改已有机器或原版工作台的库存布局，也不修改玩家存档。安装后重启游戏；联机双方均需更新。

## 既有界面与兼容说明

0.8.1 恢复原生电线显示规则：手持接线工具时显示，收起后隐藏；电路连接和供电逻辑不变。需重启游戏后验证实际画面。

只用于自动化设备，按用户提供的布局设计。普通箱子、背包和原版工作台的布局保持不变。

- 左侧搜索并点击成品；中间显示成品图标、材料/工具及“已有 / 需要”。红色数量表示不足。
- 右上18格放材料与工具；右下18格自动收成品。两边的存入、整理、取出按钮只操作自己的区域，锁定格保留。
- 点击保存应用产品和库存模式；启动/暂停按钮同时保存当前设置。关闭页面后机器才继续加工。
- 内置模式可直接接传送带：送入材料区，从成品区取出。外接模式从指定外箱加工，不使用内置库存。
- 原生背包保留。机器页面的背包快捷存入默认进入材料区，不因材料区满而混入成品区。
- 自动厨房/锻造的材料信息从实际生产计划读取，普通铁和黏土可直接使用；工具不消耗。
