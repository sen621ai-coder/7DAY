新增“自动制作工作台”（`yfAutoWorkbench`），在原来的自动化设备制造工作台中制作，需要自动化机架×3、控制器×2、电机×2。

- 支持普通工作台及手工配方中的无品质产物，包括火药、9mm／7.62mm 子弹、霰弹和零件；不支持化学工作站专属配方或有品质武器装备。
- 在半径4格内放置供电接口并接通电源，打开设备后选择产品、保存并关闭页面。上18格放材料和工具，下18格自动收成品；工具不消耗。
- 默认内置库存，传送带可直接送入材料并取走成品；也可以切换为外接箱模式。
- 沿用设备所有者的配方解锁、材料消耗、产量和制作时间加成。所有者在线且区块已加载才生产；缺电、缺料、满箱、暂停或正在打开库存时停止加工。

弹药流水线示例：

```text
煤 + 硝石 → 自动制作工作台（火药）→ 传送带
                                           ↓
弹头 + 弹壳 → 自动制作工作台（9mm 子弹）→ 成品箱
```

第二台的材料区先补入弹头、弹壳，火药由第一台传送带持续供应。弹头、弹壳也可分别由自动锻造机生产。所有传送带和对应设备应在同一区块内。

本次新增设备，不改已有机器或原版工作台的库存布局，也不修改玩家存档。安装后重启游戏；联机双方均需更新。

# 三路分拣箱（2026-09-24，已安装）

新增 `yfAutoRouter`，仅使用内置库存：背面白口进料，左侧蓝口输出筛选 A，前方绿口输出筛选 B，右侧黄口输出其他物品。接口随方块旋转。制作成本：自动化机架×2、电机×1、控制器×1、输送组件×1，在自动化工作台制作。

打开箱子，点击 A／B 按钮后搜索并选择物品；右键该按钮可清空筛选。两个筛选不能相同。保存并关闭面板后运行，三维半径4格内需要通电供电接口。传送带接背面送入，上方18格为输入，下方18格是共用出料缓存；物品按当前保存的筛选从相应出口取出。改筛选会改变缓存物品的出口；未指定的物品走其他口。堵塞时不会将指定物品改送其他口，但共用缓存最终装满后仍会停机等待空位。

旧分拣机保持原来的功能和库存。新配置添加第二筛选字段，旧存档默认该字段为空；联机客户端与服务器需同步更新。
