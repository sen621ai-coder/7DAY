# 自动化工厂实施计划

## 目标与当前版本
在七日杀 V3.2 整合包中建立可联机使用的工厂系统：自动采矿、运输分拣、农场和食物生产、装备分解、冶炼锻造、炮塔补弹。使用独立 Mod `97-AutomationWorkshop`，设备统一由自动化工作台制造。

已提交的功能基线为 **0.5.2 / Git 08ce610**，最近文档提交为 `d227a72`。本地已实现并安装 **0.7.0 原生面板、机器内置库存与传送带直连**，尚未提交或推送；当前安装与验证结果见下方最新进展。跨区块运输、分流器及真实双客户端联机验收仍待完成。

- 矿石输入 → 冶炼 → 金属库存 → 锻造配方 → 成品输出。
- 复用实际熔炼倍率、燃料与配方，不把同一份材料同时记入炉内和箱子。
- 验收：保护规则可靠、拆卸保留模组数据、掉线不重复加工、输入不足不产出。

## 默认设计
- 自动化工作台本身是原生装配台；自动机器的供电和运行由第二阶段实现。
- 核心流程先实现，再增加动画；不创建大量真实掉落物模拟传送带。
- 初版不跨未加载区运行，不补发离线产物。
- 新机器逐台开放制造配方，通过运行验收才作为可用设备发布。
- 不改既有存档地形、不替换原工作台、不更改其他 Mod 的生产配方。
