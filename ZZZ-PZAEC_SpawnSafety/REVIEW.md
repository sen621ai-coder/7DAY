# 1.0.1 复核记录（2026-09-21）

本次复核重新阅读了四个源文件，对照当前游戏/AEC DLL 的真实指令与调用约定，没有只重跑上次的测试。以下问题已修正并重新编译安装。

| 优先级 | 原问题与影响 | 修正及验证 |
|---|---|---|
| 高 | 血月的 `CalcSpawnPos` 已按原版规则挑选位置，再调用 `CanMobsSpawnAtPos` 会使用不同的水域检查策略，并对调整后的 Y 再取整，可能误拒合法候选点 | 删除重复检查，保留原版完整选点流程和新增几何校验；新增相应回归 |
| 高 | 血月、事件或直接生成的入世回调可再次触发 AEC 生成；共用线程上下文可能让内层沿用外层选点器、地点范围或已耗尽的预算 | 明确区分直接生成作用域与其他入口，并跟踪正在执行的直接生成；嵌套调用、正常返回、异常返回和批量每实体预算均已验证 |
| 中 | 其他 Harmony 补丁提前返回、使本模块前置处理未执行时，默认空状态会清掉外层上下文，随从后置处理也可能误用外层落点 | 用明确的作用域快照区分“前置处理已执行”与“未执行”；未执行时不恢复/改写，新增跳过前置处理的测试 |
| 中 | 飞行豁免仅识别 `EntityVulture`，其他原生 `EntityFlying` 派生怪物会被要求落地 | 豁免改到 `EntityFlying` 基类，新增非秃鹫飞行实体测试 |
| 中 | 锚点未加载、未初始化或非有限数时会被当成地下来源，放宽地表校验 | 只有已加载且确实低于地表的有效锚点才可进入地下规则；未知情况采用地表规则 |
| 中 | 遮盖扫描在空旷地面也逐格查询至 Y=254，血月高密度刷怪时徒增大量读取 | 使用实时 `World.GetHeight` 限制列扫描高度（不是原始地形生成器的 `GetHeightAt`）；测试验证空天空零格扫描、建筑拆改下一次可见、树木豁免和未知邻列处理 |
| 低 | 通用技能来源优先读取实体实时位置，可能覆盖幽灵召唤传入的击杀位置快照；脚底边缘高度未检查非有限数 | 优先使用调用方传入的坐标快照；拒绝无效边缘支撑高度 |

## 本次验证覆盖

- 70 项规则与实际选点运行逻辑检查。
- 16 项实际 `Sites` 适配层检查，使用模拟原生物理，包含浮动原点、碰撞层、地形网格/方块包围盒区别和列扫描边界。
- 211 项原生 DLL 指令、参数绑定、跳转标签、作用域和现有血月补丁组合检查。对血月/事件新增的分支还执行了隔离动态方法，失败路径没有执行模拟入世探针，成功路径只执行一次。
- 已核对 AEC 随从失败加入待生成列表及队列；守点事件空实体分支跳过成功条目删除；MegaHorde 走原有空实体分支，成功计数留在真实入世之后。
- 已核对 `Entity.OnDestroy` 只释放实体资源；本模块清理的是尚未入世的预制体，没有调用死亡、经验、掉落流程。
- 构建使用当前安装游戏的 Mono/Unity 程序集，替换 DLL 采用构建成功后原子替换。

运行 `tools/SpawnSafety/Test-All.ps1` 会为三组测试分别启动隔离 PowerShell 进程，避免模拟 World 类型与实际游戏类型混入同一个测试进程。

## 仍需游戏内确认的边界

当前没有进行 Unity/Mono 游戏内挂钩和真实波次实测；离线检查不能证明大型实体的实际碰撞体、动态区块加载及所有模组回调在运行中均符合预期。

规则仍然偏保守：地表入口可能舍弃桥下、建筑遮盖处或陡坡。无持久补刷队列的技能在全部候选失败后可能少生成本次怪物；这是明确返回失败后的行为，不是成功计数虚增。已存在的怪物及其之后的移动/下落不由本模块修正。

后续游戏验收应优先比较同一基地的血月波次推进、守点任务完成、随从数量，以及 `[SpawnSafety]` 的拒绝与下落记录。详细顺序见 README。
