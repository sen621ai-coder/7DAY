## 0.4.10 最终命中视觉分工

命中视觉分为三个职责：M1 管理弹药闪光/火球及命中声；按命中表面生成少量火花或扬尘；原版继续管理真实方块损伤、变化和破坏表现。移除 0.4.9 的通用褐色碎屑。原版 ExplosionData 的 ParticleIndex 统一为 0，跳过完整爆炸预制体，防止与 M1 主火球重叠；原版方块半径/伤害、实体伤害流程保持原值。

|---|---|---|
| 金属 | 单次短闪光、10 个短火花 | 主火球、6 个火花，无土尘 |
| 石材/混凝土 | 短闪光、3 个火花、灰尘 | 主火球、2 个火花、灰尘 |
| 泥土/沙/雪 | 短闪光、对应颜色扬尘，无火花 | 主火球、褐/沙黄/冷白扬尘 |
| 木材/玻璃 | 短闪光、少量材质尘，无火花 | 主火球、少量材质尘，真实碎屑交原版 |

## 0.4.6 越野与越障

越障改为接近、攀入、车腹通过、驶离四阶段；前轮上台后继续复查真实落脚面，不再要求始终看见原台阶正面。正常完成后可以识别下一处障碍；停滞、超时或安全条件失效会退出。力的截止速度仍为前进 8 km/h、倒车 4 km/h，短暂超过截止速度仅撤掉辅助力，仍在有限时间内跟踪通过进度。

左右履带独立检查落脚面，允许最多 0.20 米高差及约 15°斜向接近；中央保留净空和真实车体碰撞。倒车增加最高 0.30 米障碍的低速辅助，输出为前进的 60%。两侧真实接地但支撑狭窄时仅允许切向牵引，不增加抬头力矩；前轮登台后停止额外抬头，避免卸载车轮。

连续履带的真实碰撞接触可参与牵引，与车轮共用 0.8 m/s² 附加加速度总预算，不按接触点数量叠加力量。只有主动越障/坡地牵引时降低履带滑动阻力；退出、刹车、关闭发动机、失去驾驶员、入水、切换物理所有者或卸载时恢复原摩擦。车腹摩擦与实体碰撞保留。轮安装 Y 从 0.615 调为 0.52 米，悬挂行程保持 0.28 米；0.32/0.36 米行程在对照中没有改善跨越表现，未采用。

## M1 专用模组（0.3.0）

T16/T17 两槽，T18/T19 三槽。全部名称以 M1 开头，载具制作 100 解锁，在工作台制作；模块不分品质，拆下后可复用。升级坦克前仍须拆下所有模块。

| 模组 | 效果 |
|---|---|
| M1动力优化 | 扭矩 +30%，前进/加速/倒车上限 +25%，无额外油耗倍率 |
| M1经济巡航 | 油耗 −40%，不降低动力或速度 |
| M1附加装甲 | 正面/顶部 +4、侧面 +12、后部 +10 个百分点减伤，最高 80%，不减速 |
| M1抗蚀衬层 | 酸蚀享受完整区域装甲减伤，仍非免疫 |
| M1稳定火控 | 炮塔/炮管追踪 +50%，车体开炮反冲 −60% |
| M1辅助装填 | 装填/切弹时间 −25%，不降低追踪速度 |

动力与巡航互斥，火控与装填互斥，每种限一件。装配沿用原生界面；放置的坦克需有权限、停车离座且最近 10 秒未开火/受伤。异常组合与非法远端改装更新保留物品但隔离效果，HUD 提示后请停车拆下重新安装。服务端确认结果同步到所有客户端。通用改装和外观槽安装不开放。
