# M1 Abrams · 0.2.3 简化越野底盘版

保留 Artem Goyko 的 M1 外观，四阶共用已拆分的机械模型。配置与 DLL 已按 T16–19 军械方案更新，并采用用户确认的 **100万／150万／220万／320万耐久**、每包 **完全修满耐久**。完整合并规格位于 `tools/M1Abrams/BALANCE_DESIGN_T16_T19.md`。已按本机 V3.2 程序集编译，**尚未在游戏客户端或专用服务器内完成实机验收。**

## 安装与使用

本机已放入 `Mods/ZZ-PZAEC_M1Abrams`。保留现有 `0_TFP_Harmony`；使用关闭 EAC 的模组启动方式。重启游戏使新 DLL 生效。联机时服务器与所有客户端都需要安装相同版本的整个目录。

1. 创造栏搜索 `M1`：T16 为 `vehicleM1AbramsPlaceable`，高阶为 `vehicleM1AbramsT17Placeable`、`vehicleM1AbramsT18Placeable`、`vehicleM1AbramsT19Placeable`。
2. 按原版载具方式加油，把炮弹放入**坦克储物箱**。
3. 单人驾驶时鼠标控制炮塔，左键开火/按住持续装填射击，右键 2 倍观察，**R 切换 HE/AP**，切弹重新等待完整装填。驾驶键沿用原版。
4. 第二人进入炮手位后接管主炮，驾驶员负责行驶；炮手离开后驾驶员恢复主炮控制。
5. T16–19 装填分别为 4.8／4.6／4.4／4.2 秒，每发扣除一枚选定弹型。菜单、离座、失去焦点或输入超时中止持续开火。
6. 装甲维修包 `pzM1RepairKit` 放入坦克货仓。乘员离车、停车并在最近 10 秒未开火/受伤后，车外对准坦克**按住 G 8 秒**完全修满耐久；松键/离开/受击会中断，不扣包。满耐久时不消耗维修包。仅车主或有使用权限者可修。

生存路线：4×4 → T16 → T17 → T18 → T19。T16 要求载具制作 100；四阶分别消耗 12/12/15/18 个同阶战术组件、3/3/4/5 个心核、6/6/8/10 个攻城电容，以及锻钢、耐用合金、传奇零件等。工作台可查看完整材料。升级前置车辆须满修、空油、无改装并收起；不合格车辆会在标准制作入口被拒绝。新车空油，所有权按原生放置规则重新建立，不保留旧白名单。

HE `pzM1Shell`：中心伤害 40万/65万/100万/150万，8 米范围且有遮挡/距离衰减。AP `pzM1ShellAP`：单体 400万/800万/1600万/2800万，忽略 50% 物理抗性。仅伤害僵尸及带 hostile 标签的非玩家敌对实体，不向玩家、载具或建筑传入百万级伤害；建筑冲击单独固定为 HE 80、AP 150。弹药每批 10 发，不消耗心核/战术组件。

巡航 36/38/40/42 km/h，加速上限 48/50/52/54 km/h；正面减伤 70/72/74/76%，侧面 50/52/54/56%，后部 25/28/31/34%，顶底/未知方向 35/38/41/44%。酸蚀只享受一半防护；碰撞不享受方向装甲。低于 30% 耐久时速度上限降为 70%、炮塔转速降为 75%。马力展示值为 1500/1650/1800/2000；实际加速、坡地表现和续航尚待验证。

旧原型 ID 自动归入 T16，读取时按原 150 万上限迁移同等磨损比例，仅执行一次；旧炮弹继续作为 HE，货仓不主动清空。旧改装不主动删除，新版暂为零改装槽，专用模块仍属后续内容。原生载具“单次 99,999 伤害进入特殊摧毁”的分支已对 M1 单独修正，其他车辆不变。

## 模型与开火表现

- 三档 LOD：40,167 / 22,074 / 10,041 三角面，另有少量封口/炮管套筒。主贴图 2K、履带 1K。原始 GLB 未修改。
- 炮塔转速 25/28/31/34°/秒，俯仰 12/13/14/15°/秒，上限 +20°。根据实际模型间隙，前部最低 -6°，转向后部逐渐提升至 +4°，避免打入发动机舱。
- 炮盾隐藏底缘局部抬高至模型 Y=1.66 米，修复原模型与炮塔座圈相交；不是整块炮盾上移。
- 炮管在 0.10 秒内后坐 25 厘米，保持到 0.16 秒，0.60 秒回位。附带小幅车体反冲与可调镜头震动。
- 炮口白黄/橙色短闪、短时灯光、世界空间烟尘、地面扬尘、弹道曳光，以及炮声、机构声、装填完成声。音效为原创程序合成，非真实坦克录音。
- 0.2.2 区分弹型表现：AP 炮口闪光 0.05 秒、较窄曳光、较少烟雾，命中为火花/碎屑、短灰尘和合成金属冲击声，取消原版火球；HE 闪光 0.11 秒、较厚烟焰，保留原版命中爆炸并补充扬尘和碎屑。开火声共用合成基底，通过音高区分，炮管后坐共用。新增粒子只负责表现、不参与伤害，最多 160 个烟尘/碎屑对象；碎屑没有物理碰撞。
- 使用现有履带贴图，沿闭合路径移动履带网格并带动轮组；没有滚动整张图集。底盘仍使用原版四个隐藏轮碰撞体，不是逐履带板物理模拟。

## 当前障碍通过能力（0.2.3）

四阶共用简化底盘，不按泥、沙、雪单独减速或模拟陷车。保留原版四个半径 0.40 米的隐藏轮，悬挂行程从 0.15 米增至 0.28 米，阻尼从 18,000 增至 28,000；安装高度补偿半行程差 0.065 米，实际加载站姿仍需实测。下车体前后改为凸形倒角碰撞体，保留中段腹部及原有宽度，上车体和炮塔碰撞不变。

前进速度低于 8 km/h、两侧原生轮真实接地、发动机运行且有油时，正面接近 0.12–0.60 米台阶可触发有限牵引和抬头辅助。左/中/右探测必须找到接近等高的平台及其后方落脚面，平台上方不能有障碍；急转、刹车、侧倾、入水、单侧失去接地会取消辅助。每次最多 2 秒，连续约 0.6 秒无进展则停止，需后退至少 0.5 米重新尝试。倒车仍用原生物理，无专用倒车攀越辅助。

接地时增加有限俯仰/侧摇阻尼，低速保留差速转向；15–35 km/h 间将原生轮转向上限从 25° 平滑收紧到 8°。低耐久的既有限速规则保留，越障辅助输出同步衰减。坡道、沟壑仍由原生接地与碰撞决定，涉水沿用原版限制。没有新增 14 点支撑、地表陷车、自动翻正、材料碾碎或悬空托举。

**0.60 米是检测上限与实机验收目标，不是已经实测通过的承诺。** 凸起仍可能卡底，整格垂直方块不能依靠辅助攀越。配置中的 upAngleMax=45 也不是已验证的爬坡能力。客户端与专用服务器内的越障、站姿、碰撞网格及联机交接尚待验收。完整实现边界与验收清单位于 `tools/M1Abrams/OFFROAD_DESIGN.md`。

本机没有 Unity Editor，因此采用运行时读取网格并克隆原版载具基础结构的资源加载方式，**没有生成 Unity AssetBundle**。可编辑的 Blender 和 FBX 文件位于 `tools/M1Abrams/Generated`，安装此模组无需 Blender。

## 参数与范围

当前整合另有共享模块 `ZZZ-PZAEC_SealedCabins`：M1 四阶与 MD-500、阿帕奇统一提供密闭座舱环境防护。车内所有乘员隔绝环境辐射、炎热和寒冷，熄火/缺油仍有效；已有累计辐射不清零，中暑和冻伤按原规则恢复。下车后恢复环境判定。该功能需要同时保留共享模块的 DLL 与配置，详见其 README；不等于感染、流血或怪物直击免疫。

`Config/vehicles.xml` 中的 `m1FireKey` 设置开火键，`m1CameraShake` 设置 0–1 的镜头震动强度。装填、弹速、伤害与俯仰范围在 `Source/M1Rules.cs`，修改后需重新编译。

服务器负责乘员权限、炮塔角度、扣弹、冷却、弹道、伤害与维修；客户端负责特效。射击方向使用实际炮管朝向，炮管受阻或尚未瞄准时不发射。HE/AP 弹速为 250/350 米/秒，射程上限 600 米，计入飞行距离与寿命；通过原生 DamageEntity 保留死亡/伤害响应，避开手持爆头 ×5 入口。

当前复用原版发动机声音与乘坐动作，没有独立驾驶舱内饰或可用机枪。炮塔角度和装填状态是会话内状态，世界重新载入后重置；同次会话换座不会重置装填。网络时序补偿尚未做真实延迟环境测试。

## 已验证与待验收

验证入口为 `tools/M1Abrams/Test-All.ps1`：检查模型/四阶配置、数值规则、底盘辅助条件/台面判定/防重复攀越/高速转向策略、网络包、模拟库存的实际开火方法、实际迁移与维修方法，以及本机原生挂接与大耐久兼容条件，最后重新编译 DLL。可见模型未改变，沿用此前通过的 432 组炮管姿态检查。离线规则测试不等于 Unity 碰撞、悬挂与网络物理实测。

实机按以下顺序验收：

1. 启动日志出现 `[M1-Abrams] Model, dual-seat main gun and firing presentation installed.`，无相关异常；创造栏图标、放置预览与生成实体均为 M1。
2. 检查上下车、静态站姿、坡地转向、倒车、碰撞与保存重载；用 0.15/0.30/0.45/0.60/1.00 米台阶验证低速越障，包含斜入、顶墙、刹车、缺油、单侧悬空、深水；检查履带近景和三档 LOD。
3. 储物箱放 10 发炮弹，射击后仅减 1；冷却期间换座不额外开火。菜单/离座停止射击，空弹药无法开火。
4. 查看炮管回位、闪光、烟尘、日夜亮度、近远炮声、镜头震动，以及贴墙/朝向车尾时的阻挡提示。
5. 双人联机验证炮手优先、退出恢复、旁观者特效一致、专用服务器命中；在 100–200 毫秒延迟下重复验证扣弹与特效不重复。
6. 验证四阶满耐久、旧车半损迁移、R 切弹重置装填、AP 单体/HE 遮挡、各方向与酸蚀受伤、10 万以上单次伤害不触发提前摧毁。
7. 验证 G 维修一次完全修满耐久、满耐久不消耗、中断不扣包；原版维修入口拒绝；损坏/带油/带模组的前置车辆不能升级，正常升级仅消耗一次。检查当前整合包自动化制作与储物扩展兼容性。
