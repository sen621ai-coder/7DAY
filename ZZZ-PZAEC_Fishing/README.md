## 鱼种与重量（0.2.7）

每次抛竿随机选定鱼种与重量，漂相不提前披露鱼种或真假口。八种鱼使用共享动画骨架，并按鱼种调整体型比例、按重量缩放；目前没有各鱼种独立精细模型。以下为游戏内调参范围，不是现实鱼种重量分布。

| 鱼种 | 重量范围（kg） |
| --- | --- |
| 鲫鱼 | 0.30–1.05 |
| 鲤鱼 | 1.50–5.25 |
| 草鱼 | 2.25–7.875 |
| 鲢鱼 | 1.80–6.30 |
| 鳙鱼 | 2.40–8.40 |
| 白条 | 0.0525–0.18375 |
| 鳑鲏 | 0.03–0.105 |
| 太阳鱼 | 0.15–0.525 |

同种鱼相对基准重量增加时，巡游和爆发推力按重量比的平方根增加，耐力按重量比增加。大鱼可能超过入门鱼线承受力，需要主动让力。上岸显示鱼种、重量和鱼肉数量；每 0.25 kg 向上取整为一份对应鱼种鱼肉，至少一份。例如 3 kg 鲤鱼给 12 份鲤鱼肉。每份鱼肉可在篝火烤架烹饪成对应烤鱼，沿用烤鱼食物效果。

鱼种索引与实际重量进入原生角色保存；背包满时保留整批鱼肉，腾出一个空格后领取，不拆批、不重复发放。旧版缺少鱼种字段的待领取记录仍按鲤鱼读取，旧整鱼物品定义保留，旧鲤鱼可通过制作转为 12 份鲤鱼肉。

## 操作

已准备专用 `FishingTest` 存档时，首次进入会从该存档的 `pzaec-fishing-test-kit.xml` 领取钓竿 2、蚯蚓 200、烤鱼 10。发放限定文件中记录的绝对存档路径；已发数量跟随角色原生保存，背包满时等待空格，正常存档没有该请求文件便不会发放。

关闭游戏后运行 `tools/Fishing/Integration/Install-TestBuild.ps1` 安装已构建的正式模组 DLL，重新启动进入单人存档。配置在 `Config/Fishing/settings.xml`。

1. 制作并装备 `pzaecFishingRodBasic`，携带 `pzaecFishingBaitWorm`（腐肉制作）。朝下瞄准 6.5 米内、深度至少 0.6 米的水面，左键抛投。有效抛投消耗 1 蚯蚓；无效位置/缺饵不开始，抛投后取消不退饵。
2. 观察漂目自行判断，左键提竿，不要求同一时刻后拉鼠标。轻晃、下顿、顶漂、走漂可能来自试探或碰线，提竿不保证中鱼。空竿后重新抛投；没有提竿时浮漂会回稳，继续等待。界面不提示真实吃饵状态或提竿倒计时。
3. 中鱼后后拉鼠标抬竿遛鱼，左右移动鼠标侧压，前推放低竿身，配合 WASD 走位。4.5 米手竿配 4.5 米固定线，没有右键收线、泄力或自动放线，也不会自动替玩家后退。
4. 左 Alt 自由观察，左 Ctrl 暂停控竿以挪回鼠标，Esc 取消。切装备、受击、死亡、菜单/失焦、游泳、车辆和世界退出会释放操作。
5. 鱼疲劳后抬竿引到近岸即可自动收获。鱼肉保留鱼重和结算编号，每次鱼获整批占独立背包格；满包保留待领取结果，空出格子后自动领取，领取前不能再次抛投。

0.2.2 在左侧屏幕中央加入“漂目放大”窗口，六段漂尾、水面线和露出目数同步原生模拟的浮漂浸没比例及倾斜；正常站漂约四目。急促下沉显示顿口，全部入水显示黑漂，上浮增目显示顶漂，水平移动显示走漂。标签根据实际位移识别，不按咬钩阶段播放预设动画。有效吃饵阶段显示“左键提竿”，中鱼后显示“后拉鼠标遛鱼”。原状态面板移到右上角，避免遮挡漂目。

0.2.3 左右侧压会带动原生人物视角，转动量跟随受力后的实际竿身角度；Alt 保留自由观察，Ctrl 挪鼠标不会转动。右侧显示醒目的拉力及鱼体力条，80% 断线拉力标记为危险，鱼体力降到上鱼阈值时提示引向近岸；鱼离开视野会提示左右方向。拉力增加时抬竿、侧压需要更长鼠标行程，放低竿仍可及时卸力。鱼以玩家位置作为逃跑参照，冲刺向远处、恢复时侧游，避免长竿竿尖在鱼前方时把逃跑方向算向岸边。

注意：`_disabled-` 目录前缀本身不会停用模组；只要目录中仍有 `ModInfo.xml`，游戏仍会加载。构建及测试脚本会自动寻找包含该文件的钓鱼目录。

0.2.4 将右手握点从武器模型挂点改为食指、中指、无名指弯曲指节与拇指之间的握持中心。准备状态、抛投根部和遛鱼画面统一使用该握点，第一人称手部 FOV 转换在计算握点后执行。原生手部骨骼不可用时回退武器挂点；实际手指贴合仍需游戏画面验收。

0.2.4 同时增强鱼力：巡游推力 9→18 N、冲刺推力 50→85 N，巡游/冲刺目标速度 0.5/3→0.9/3.8 m/s，冲刺 2→2.6 秒、恢复间隔 4→3.2 秒，体力储量 450→1200 J。鼠标阻力参考拉力 110→70 N、最低响应 25%→18%，线承力 90→110 N；危险提示随线承力自动调整。固定种子对比测试检查实际线拉力而非仅检查配置数值，并保留默认配置成功上鱼验证。

0.2.5 增加主动用力（配置 `Controls.EffortEnabled`）：拉紧线时鱼会缓慢压低竿、把竿带向自己，持续后拉才能顶住。逆向侧压阻力及消耗更大，顺向让力更容易；低体力时抬竿与逆向侧压变慢，前推放低竿始终可用。消耗直接进入游戏原生玩家体力，放低竿停止额外消耗，恢复由原生饮食、Buff、走动等机制决定。等口不耗钓鱼体力；Alt/Ctrl 保持握竿时仍有持竿消耗，但不注入控竿动作。右侧加入“你的用力”和原生体力百分比，疲劳时提示放低竿恢复。配置默认开启，本版同时包含握点修复和鱼力增强。

漂目与右侧状态条向屏幕中心内收，漂目右边界约在画面 32%，状态条左边界约在 68%，保留中间水面观察区域；窄屏自动限制在边缘安全距离内。

上方提示缩为三行：状态、当前操作、常用按键。拉力和体力只在条形面板显示；抛竿、中鱼等重复弹出说明不再叠加，上魚、失败、背包满等结果提醒保留。

0.2.6 默认开启 `Hook.NaturalBites`。接触、试探与含住饵分开计算；每轮预先确定鱼是否含饵，提竿时还要满足时间和实际饵位移条件，不在点击时临时抽签。假口也会通过受约束的饵位移传递到浮漂，短暂拉动后逐渐释放；未提竿的接触回稳后进入下一轮等待。增加轻微背景水面扰动及不规则接触起伏，漂相标签只根据运动识别。移除旧版的鱼有口、咬实、提竿倒计时、黄色可提竿提示，以及吃口事件产生的额外水纹提示；中鱼前不显示鱼体力条。

待领取/完成状态使用玩家原生 Buff CVar，与背包进入同一 PlayerDataFile。进行中的鱼战不保存。异常库存写入停止自动重试；完整玩家保存/重载及崩溃一致性未验收，不宣称任意故障下 exactly-once。

## 构建与验证

从 Mods 工作区运行：

```powershell
pwsh -NoProfile -File tools/Fishing/Integration/Build.ps1
dotnet build ZZZ-PZAEC_Fishing/Source/PZAEC.Fishing.csproj -c Release
pwsh -NoProfile -File tools/Fishing/Integration/Inspect-Native.ps1
pwsh -NoProfile -File tools/Fishing/Integration/Test-Contracts.ps1
pwsh -NoProfile -File tools/Fishing/Integration/Test-Modules.ps1
```

两种构建均只输出到 `tools/Fishing/Integration/artifacts/build/`。安装脚本只复制正式 PZAEC.Fishing.dll，并备份已有版本；不要安装探针程序集。移出根目录的 PZAEC.Fishing.dll 并重启即可禁用钓鱼运行时。

原生探针另开隐藏的独立游戏进程及全新 `FishingM0_Isolated` 存档：

```powershell
pwsh -NoProfile -File tools/Fishing/Integration/Start-NativeProbe.ps1
# 根据 artifacts/native-session.json 中的 Log 查看 [FishingM0] RESULT。
pwsh -NoProfile -File tools/Fishing/Integration/Stop-NativeProbe.ps1
```

启动脚本立即返回，不自动等待。探针仍会加载安装目录的整合模组，**隔离的是存档及测试产物，不是全部第三方模组**；当前林业模组需要图形设备，不能使用 `-nographics`。停止脚本核对 PID 与启动时间，只关闭自身测试进程。

## A 提供的运行时

- `LocalFishingRuntime`：装配 B/C/D/E、装备识别、选点扣饵、生命周期、表现和奖励接线。
- `SessionDriver`：固定步长、输入累积、环境插值、事件去重和释放；物理竿尖由 B 计算。
- `NativeWaterQuery`：原生水格/已加载区块查询；水面为体素估计，不能声称匹配水面着色器的波浪。
- `NativeControlLease`、`NativeInputHooks`：仅钓鱼会话持有输入租约。保留原生 Update 和 MoveByInput，局部覆盖镜头输入及移动意图。
- `MovementBridge`：在原生移动轴上合并额外后退，并仅衰减逆拉力分量；不修改玩家 Transform。
- `CatchSettlement`/`NativeCatchRecord`：本地授权会话结算、待领/已领原生保存记录。多人路由尚未接线。

待机与抛投均显示 D 的钓竿。0.1.2 对原生第一人称 FOV 进行握点投影转换，装备采用原生石斧闭合握持姿势；物理竿根仍读取未转换的原生挂点。面板放大并移到左上侧，咬实时增加中央提示。真实手指贴合及左手卷线动作仍需实机复核和完善。

0.1.1 修正正式配置下鱼体力恢复过高、持续遛鱼仍无法进入上岸门槛的问题；保留 450 J 耐力，将受钩恢复功率从 8 W 调为 0.2 W。3 个种子的正式配置回归可在约 92–107 秒完成上岸，这些是固定脚本测试时长，实际操作会有所不同。提竿容许点击前 0.12 秒内的有效抬竿，或点击后 0.2 秒内的抬竿；不扩大咬钩窗口，也不会让仅点按钮自动中鱼。

现在日志记录接受抛投、点击提竿时的鼠标量、状态变化、5 秒一次的受力/体力、关键事件及退出原因。鱼战手感、线漂几何、多人和崩溃恢复仍需验证，详见总进度。
