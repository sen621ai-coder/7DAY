# 阿帕奇清群支援平衡（2026-09-18）

用户选择：清群与火力支援，Boss仍需地面配合。本轮调整伤害和耗材，保留飞控、射速、射界、热量与原生伤害结算。

沿当前普通怪定义继承链核对到原版zombieBiker物理抗性20、zombieSoldier 50、zombieDemolition 60；Arlene链未发现物理抗性条目。不是所有怪的统一抗性，也不是实时EffectManager查询结果。任务词缀、buff、难度与命中部位另行影响结果。

## 新参数与估算

- 机炮实体基础伤害120→20,000，方块仍为8。360发/分钟，每发6热量、每秒冷却16、100停火、35恢复。
- 火箭实体基础伤害250→100,000，方块仍为50。三连发、每轮起始间隔1.5秒，实体爆炸半径10米。
- 不增加穿甲、追踪或Boss百分比伤害。机炮原生命中接口仍受本整合已有玩家爆头×5补丁及其他修正影响。

机炮计时使用实际ApacheWeaponRules.Gate模拟，步长1毫秒，包含过热恢复，从首发开始计时，不含索敌、网络和弹体飞行。60%减伤和半额爆炸是敏感性估算，不代表所有部位或爆炸都采用同一减伤公式。爆炸距离、遮挡及脱靶会降低输出；满额火箭伤害不是保证整个爆炸半径内全部敌人都吃满。

实际热量门控下180秒持续按住机炮，共495发，平均基础DPS约55,000，短时未过热DPS120,000。火箭名义长期每秒2枚，满额单目标基础DPS200,000。两人合计长期基础DPS约255,000。即便忽略Boss一切减伤、只算躯干且所有火箭命中满额，T19仍约需17分钟；一轮三枚火箭仅占各阶Boss血量0.75%、0.375%、0.20%、0.115%。这是清理护卫、分担压力的定位；爆头、地面破甲和特殊弱点配合可提高效率。

## 耗材

保持车辆制作100级、普通工作台和原专用弹药ID；飞机货仓每实际开火消耗1发。

- 50发机炮弹：弹头150、弹壳100、火药500、锻钢25，基础180秒。每发火药3→10、锻钢0.1→0.5。
- 5枚火箭：火箭弹头5、弹壳5、火药150、胶带10、汽油1000、锻钢10，基础90秒。每枚消耗一套完整火箭弹头/弹壳，取代原先一套产5枚。

这是首轮配置基线，先保留两种弹药，不新增四阶装备树。材料约束持续出击，机炮受热量约束，火箭通过密集落点取得面积收益。
