# Buster 配套停机坪外观

2026-09-22，根据用户要求调整停机坪，使其与 Buster Drone 配套。

`CargoDroneHubModel.cs` 构建带支撑底座的工业停机坪：灰白倒角装甲台面、深色防滑区和结构框架、四侧散热格栅、角部立柱与紧固件、少量土黄色警示标记、绿色分段引导灯，以及低于落点的嵌入式控制面板。指示灯和屏幕条是外观装饰，不冒充已接通的真实供电或充电状态。无人机模型和材质不变。

外观保持 2×2 水平占地，底座高度不超过一格。世界模型原点仍为 Hub 身份位置上方一格；停靠锚点统一为该原点上方 1.2 格，与返航位置匹配。Buster 停靠姿态最低顶点约为 -0.2294026，防滑台面顶部因此设为 0.9706，修正旧外观锚点 0.58 与实际返航高度不符的问题。

部件在创建时按六种材质合并为六个固定网格，避免每个格栅、螺栓单独绘制；临时构造网格随即销毁，最终网格与材质由模型拥有并在销毁时释放。装饰模型不增加物理碰撞体。范围、派单、库存和存档流程不变。当前仍是现有隔离 QA 世界中的外观，未增加正式可制作停机坪方块或解除真实库存 QA 限制。

验收覆盖六个材质网格、两格占地/一格高度、锚点与返航高度一致、支腿落点、单独停机坪和组合停靠 PNG，以及原生世界库存搬运回归。原生结果记录于 `tools/CargoDroneImplementation.md`。
