# 阿帕奇护甲强化与乘员防护

## 2026-09-22 实施更新（1.27.12）

用户已要求实施。以下历史建议和死亡排查记录保留；当前实现状态以本节为准。

- 阿帕奇机身：普通外部攻击减伤 75%，原生爆炸处理期间减伤 60%，碰撞及直接累计损伤减伤 50%；每次最多损失最大耐久的 15%。基础耐久和维修消耗不变。
- 修正原生 ApplyDamage 将单次 99,999 及以上伤害视作强制摧毁的问题，仅对存活阿帕奇放宽该阈值；耐久耗尽后的原生损毁仍保留，显式自毁也保留。
- 实际坐在存活阿帕奇主驾或副驾座位的玩家：普通外部攻击减伤 90%，直接爆炸减伤 80%，碰撞/跌落减伤 75%；每次最多损失最大生命的 20%。原生机身传给乘员的匿名伤害按普通攻击处理。
- 下机或机身已毁立即失去座舱保护。不豁免饥饿、疾病等内部生存伤害，不提供异常状态免疫。连续多次攻击仍可致死。
- 减伤在伤害响应生成时执行，收到网络响应时不再重复减伤；同步修正因减伤失效的致死标志。房主/服务器与全部客户端必须使用同版 DLL。
- MD500 及其他载具不受此补丁影响。
- 验证：使用当前游戏程序集编译成功；真实 Harmony 补丁测试夹具 28 项通过；Mono.Cecil 核对当前 V3.2 两个响应注入点及原生摧毁阈值通过。尚未进行游戏内联机实测，不能据此确定历史死亡的具体凶手。
- 源码：99-AEC_T16_RuntimeFix/Source/ApacheArmor.cs；复现测试：pwsh -NoProfile -File tools/Test-ApacheArmor.ps1。

## 原始建议（历史记录）

记录日期：2026-09-22。用户要求先记录，不修改数值或安装。

- 基础耐久保持 100 万。
- 普通攻击、枪弹减伤 75%。
- 爆炸伤害减伤 60%。
- 碰撞伤害减伤 50%，保留高速碰撞危险。
- 单次扣血最多为最大耐久的 15%，防止一次异常高伤摧毁。
- 维修消耗暂不改变；仅针对阿帕奇，MD500 不受影响。
- 实施前核对服务器实际耐久扣除入口、伤害类型及碰撞路径，避免重复减伤或绕过。
- 这些比例是设计建议，未实装、未测试；载具护甲与乘员防护应分别评估。
