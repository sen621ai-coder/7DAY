# 自动林场 v5：计划与执行记录

## 执行计划与结果

1. **初始化和失败隔离——完成**
   - 预检两份 YFF1 网格头和 23 张 PNG 的存在性、可读性及文件头；完整网格尺寸、索引和贴图解码仍在实际创建时验证。
   - 独立 Harmony 补丁域，安装异常撤销本域补丁；外层局部捕获，继续安装其他运行系统。
   - 运行时新建的 Mesh、Material、Texture 明确登记为自有资源；创建失败回滚本次分配，不销毁借用的原生资源。
2. **资源检测、恢复和实例绑定——完成**
   - 共享资源和恢复副本在本进程内保留，副本从不直接赋给 Renderer。
   - 每五秒至多一次共享资源检查；丢失贴图从本地文件重载，材质和网格从恢复副本重建；原生着色器失效时重新获取原生模板。
   - 模型实例保存序列化 Renderer、MeshFilter、MeshCollider 绑定。Unity 克隆时引用随对象重新映射，恢复后更新已加载实例、缓存和碰撞网格。
   - 保留 v4 回收保护，设置 retiring 标记，防止恢复器在回收阶段重新绑定材质。
   - 尺寸分别缓存，验证大尺寸→紧凑尺寸→大尺寸复用正确。
3. **动画失败恢复与诊断——完成**
   - 每次激活初次尝试失败后，最多三次重试，间隔 5、15、30 秒；失败不阻断原生建筑交互与生产。
   - 资源确实恢复并进入新代次时，允许重新绑定；区块卸载取消旧世界上下文及重试。
   - Update/Poll 异常进入同一受控降级路径，避免逐帧异常。
   - 删除已不用的淡出材质及其释放逻辑。日志记录材质实例、着色器、纹理数量、资源丢失、修复代次与实例重绑；生命周期计数按首次/每 25 次摘要输出。
4. **检查、安装和同步包——代码检查完成**
   - 最终产物为当前全部源码构建的共享运行库，不回退其他任务修改。
   - 安装步骤核对进程已退出、源码未在编译后更新，并备份当前 DLL、校验安装和压缩包哈希。

## 已执行验证

- 正常资源预检；同时缺贴图、损坏远景文件时汇总报错。
- 动画三次延时、重试耗尽、卸载重置、恢复后不重复重试、资源修复后重新开放预算。
- 真实模型构建代码通过离线适配器导出，验证材质、网格与碰撞引用。
- 主动销毁共享材质、贴图、网格：两个实例恢复同一共享材质，渲染网格和碰撞网格一致。
- Renderer 材质槽被清空后恢复；创建失败回滚不影响已提交资源；正在回收的实例不重绑。
- 原生着色器对象被销毁后重新获取；不同尺寸缓存隔离。
- 原有机械循环 40,002 个采样、生产状态、空材质、采集器产出/燃料/满仓/插件降级检查通过。
- 使用本机游戏程序集完整编译通过。

## 实际边界

- 离线故障注入不是 Unity 实机 GPU 渲染测试；它不能确认“着色器对象仍有效但驱动实际输出紫色”的情况。
- 持续缺文件、无可用原生着色器等外部条件无法靠重复构建解决，资源恢复失败按 60 秒退避并保留诊断。
- 缺少资源导致启动预检不通过时，补齐文件后需重启游戏安装显示补丁。
- 恢复副本增加一份生成网格及材质的驻留开销，换取无需破坏原生 TileEntity 的显示恢复；贴图副本不重复保存，按文件重载。
- 本轮没有完成专用服务器无图形环境、真实双机长时间运行验证，也不承诺仅凭离线检查彻底排除紫色根因。
- 所有恢复操作只作用于显示资源及其网格碰撞绑定，不修改库存、燃料、产出或存档位置。
