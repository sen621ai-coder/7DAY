# 台钓 0.2.7 多鱼种、重量与鱼肉

加入鲫鱼、鲤鱼、草鱼、鲢鱼、鳙鱼、白条、鳑鲏、太阳鱼。Fish 配置作为鲤鱼基准，FishCatalog 给不同鱼种设置质量、推力、耐力、阻力和试探节奏，并使用独立混合的会话种子选择鱼种与基准重量的 0.5–1.75 倍。开始抛竿后不更换鱼种，不提前透露鱼名或真假口。

同种鱼越重，巡游和爆发推力按相对重量平方根增加，耐力按相对重量增加。动画骨架共享，体型比例按鱼种调整、模型尺寸按重量缩放；没有各鱼种独立精细模型。小鱼最低质量放宽至 0.005 kg，生产最轻鳑鲏为 0.03 kg。

鱼获改为对应鱼种鱼肉：每 0.25 kg 向上取整一份，至少一份。原生背包一次写入完整批量，不在背包满时部分发放。上岸显示鱼种、实际重量和数量，鱼肉可烹饪为对应烤鱼。保存增加稳定鱼种索引，旧版缺少字段时仍为鲤鱼；待领取重量和重复结算保护保留。旧整鱼物品仍存在，旧鲤鱼可制作转换为 12 份鲤鱼肉。
