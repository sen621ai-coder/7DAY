# 台钓 0.2.5 主动用力

本版合并握点修复、鱼力增强以及主动用力机制，默认 Controls.EffortEnabled=true。拉紧线时，鱼按负载缓慢压低竿并把竿带向自己，持续后拉才能对抗。逆向侧压受力和消耗更大，顺着鱼让力可更快移动竿。原生玩家体力不足时抬竿和逆向侧压响应减弱，前推放低竿仍然可用。放低竿停止额外耗力，体力恢复仍由游戏原生机制负责。

用力按固定物理步计算，通过 SessionDriver 汇总本输入帧消耗，再使用 EntityPlayerLocal.AddStamina 扣除原生体力。等待吃饵不消耗；无物理更新帧清空本帧消耗，避免重复扣除。Alt/Ctrl 不注入竿身动作，同时保留持竿消耗，避免暂停输入凭空抵挡鱼力。退出释放用力显示，实际玩家体力不退款或重置。右侧新增橙色用力条、原生体力百分比和恢复提示，适配小屏面板高度。

验证：

- 39 项控制测试通过，包括停手降竿、后拉抵挡、低体力响应、可放低竿、逆向侧压、等口无消耗及 60/120/240 Hz 消耗一致性。
- 57 项模块检查、21 项结算及目标检查通过。新增三个生产配置种子的玩家体力循环，使用 100 点体力、8 点/秒的确定性恢复夹具（非原生恢复速度承诺），均能成功上鱼，分别累计消耗约 380/536/458 点，发生 2/4/3 次恢复循环，最低体力约 30 点。无更新步不能重放旧耗力。
- 内容在 .NET 8 和 .NET Framework 各 107 项通过；32 个模组 4069 项 XML 操作合并通过。
- 鱼力比较固定握竿姿态后检验实际拉力增强；主动用力与疲劳后的上鱼能力另行测试，不能把握竿姿态不同造成的拉力差当作鱼本身推力差。

真实握持像素、操控手感、饮食/Buff 改变原生体力恢复后的平衡仍需玩家实机验收。
