# 台钓 0.2.6 漂相与假口

生产配置启用 Hook.NaturalBites。每轮接触预先确定鱼是否实际含饵，提竿时不重新抽签；假口产生短暂牵引后衰减回漂，真口也需要进入有效含饵阶段并产生足够的饵位移才能中鱼。未提竿时继续等待下一轮接触，不再因错过窗口自动结束。水面轻微起伏、试探、短促下顿与回漂均反映到浮漂物理位移。

界面不显示是否咬钩、可提竿标记、倒计时或黄色提示；等待、试探和含饵阶段显示相同提示。漂相只按实际漂目、速度和位移判断，保留顿口、黑漂、顶漂、走漂等形态。关闭接触事件附加的提示水波，钩住鱼之前不显示鱼体力或拉力面板。空竿只提示重新抛竿，不揭示真假口。

验证：

- 44 项模拟测试通过。64 个固定种子在首次漂动作窗口后相同时间提竿，41 次中鱼、23 次空竿；验证假口回漂继续等待、过早提竿失败和多轮接触的确定性重放。
- 106 项模块检查和 21 项结算及目标检查通过。生产配置另用 32 个种子验证中鱼和空竿均存在、空竿无奖励；遛鱼与体力回归用例关闭自然吃口以隔离取得鱼的步骤。相同漂位移在三个等待阶段产生相同漂相且不披露提竿许可。
- 内容在 .NET 8 与 .NET Framework 各 107 项通过；32 个模组 4069 项 XML 操作合并通过。
- 使用游戏原生引用编译 41 个源文件成功，git diff --check 通过。握点及原生体力路径沿用 0.2.5 已通过的 56 项原生探针验证，本次未重复运行探针。
