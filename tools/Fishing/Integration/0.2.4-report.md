# 台钓 0.2.4 握点修复

用户反馈手在竿子上方。0.2.3 对齐的是 GetHoldingItemTransform 返回的武器模型挂点，该挂点并非手掌握持中心。0.2.4 用实际第一人称骨骼 RightHandIndex2、RightHandMiddle2、RightHandRing2 计算弯曲指节中心，再取该中心与 RightHandThumb2 的中点作为竿柄中心。此点随骨骼动画变化，不使用屏幕向上平移常量。

闲置握竿、物理抛投根部和本地遛鱼渲染统一使用该握点；第一人称与世界 FOV 之间的转换保留，在算出实际手部握点后执行。切换模型会重新解析骨骼，退出清除缓存；骨骼不可用时回退旧武器挂点。

构建使用实际游戏 Unity 与 Assembly-CSharp 引用。原生探针增加真实 SDCS 骨骼存在检查，以及抬竿、侧压姿态下握点随手旋转平移、释放缓存检查。探针不替代真实玩家动画或手指与竿柄像素贴合验收。
