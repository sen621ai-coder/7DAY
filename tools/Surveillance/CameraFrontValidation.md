# 1.0.12 真实镜头前后方向

## 根因

此前的方向测试使用人工构造的正 Z 节点，证明了画面上下端正，却没有验证实际摄像头镜头正面。此次读取游戏真实 motionsensor 模型：`turret_cone` 局部网格中心 `(0,0,-0.39)`，半尺寸 `(0.39,0.39,0.39)`，视野体积位于负 Z；无旋转安装时 Cone.forward 为世界 `(0,0,-1)`，锥体实际展开方向为世界正 Z。模型中名为 camera 的节点也朝世界正 Z 附近（带约 4.25° 俯角）。

取景错误来自把 Transform.forward 当作该模型的镜头朝向。修正为 -mount.forward，保留世界向上校正和接近垂直俯仰时的退化回退。位置仍取原生 Cone，动态跟随原生转头、俯仰及方块安装旋转。

## 验证

- 使用真实原生模型，调用原生 Init / SetYaw / SetPitch。
- 四个安装方向，每个方向测试 yaw/pitch = (-35,-15)、(0,0)、(35,15) 度，共 12 组。
- 由实际锥体网格中心到原点的世界向量独立确定前方。前方 3 米绿色方块，后方 3 米红色方块。使用旧正 Z 取景必须看到红色；调用生产 Follow 后必须看到绿色且前向点积 > 0.999。
- 沿用隔离 GPU 验证的画面上下方向、屏幕 UV、目标标记、最后完成帧保留与前后面状态文字检查。
- Build.ps1 / Test.ps1 已通过。原生 D3D11 图形测试通过，日志：`.local-tests/Surveillance/NativeSmoke/run-60694ef708d647309aecbc7682035c3d/game.log`；12 组真实模型前后对照及全部既有图形回归均 PASS。用户存档未修改；隔离测试不是实际联机客户端操作录像。
