# 大屏目标红框 1.0.3

功能：在每块大屏的“设置监控”中切换“目标红框”，默认关闭。开关独立随世界存档保存，服务器校验屏幕GUID、配置修订、距离和管理权限。旧存档缺少targetMarkers属性时默认关闭。所有联网端需统一安装1.0.3。

显示策略：活着的EntityZombie及实体定义中bIsAnimalEntity为真的动物，排除玩家和尸体；普通人形NPC不标记。动物包括中立动物，不依据当前仇恨目标或宠物阵营判断敌我。非标准继承的模组敌人需要另做适配。

识别范围48格，最近24个合格候选，每次成功视频帧最多32次遮挡射线和16个框。只扫描客户端已加载实体；投影小于4像素、完全出画、镜头后方、跨近裁剪面时不显示。躯干或头部至少一个采样点被原生射线直接命中才显示；完全被墙/门挡住时不显示。部分身体可见时框选的是实体整体外接范围，并非逐像素轮廓。

框选位置与成功的视频帧同时计算，不能使用玩家主相机的坐标，也不会用新位置覆盖旧视频。画面超时、黑屏、离开观看或开关关闭时隐藏红框。全体观看屏幕关闭该功能后，不运行目标检测。

叠加层使用单独Mesh及材质，按屏面实际前表面UV定位。视频纹理仍按摄像头共享；同摄像头被两个屏幕使用，其中一个关闭红框不影响另一个。检测每镜头每帧最多执行一次；所有红框渲染器在监控相机绘制时临时隐藏，避免拍屏递归。

## 实机验收顺序

1. 两屏共用摄像头，一块开红框一块关。镜头内安排活丧尸、动物及玩家，确认只有开关开启的屏幕标记丧尸/动物，视频一致。
2. 移动、爬行、飞行目标进入/离开画面，验证框随视频采样，不跟玩家视角移动。检查四方向屏幕、不同纹理尺寸、浮动原点变化后的定位。
3. 目标走到实体墙后及关闭的门后，框应消失；露出头部可被识别。玻璃、栏杆等按原生射线碰撞规则可能保守遮挡。
4. 切频道、断电、关开关、移出视野及超过500ms旧帧超时，应同时清理红框。
5. 保存重载，第二客户端观看，确认开关保留、同步且不同屏幕独立。旧版本客户端不混用。
6. 目标密集场景开启性能记录，对比红框开/关，确认上限与额外开销；此版本不承诺32次射线对所有基地都无明显成本。
