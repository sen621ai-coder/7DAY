# 自动采矿机与林场

配置在 `98-AECxProjectZ_Tweaks`，累积存储补丁在 `99-AEC_T16_RuntimeFix`。
原 `95-AutoForestry` 已合并，设备和木材包 ID 保持不变。

- Project Z 六种采矿机、新增黄铜机、自动林场均为 3 列 × 2 行。
- 不装资源打包器：每格最多 3 包，合计 18 包。
- 装资源打包器：每格最多 6 包，合计 36 包。
- 原生燃料消耗、生产周期、配件增产/加速和存档网络序列化保持使用。
- 产物累加到尚未满的格子。全满暂停；取走后补充。
- 拆下打包器不会删除已存入的包；超过新上限的格子停止补充。
- 七种资源采矿机（铁、铅、煤、硝石、黏土、油页岩、黄铜）基础每500汽油产出一包6000资源，折合每1000汽油12000资源。配件增产效果保留。
- 黄铜机在改良工作台制造，每包 6000 黄铜。
- 林场每包 12000 木头，无需树苗。

客户端与服务器均须更新上述两个模组并重启。
测试：`tools/Test-CollectorBatchStorage.ps1` 验证实际补丁的容量、累加、补充、配件降级及作用范围。
编译：`tools/Build-RuntimeFixRoslyn.ps1` 使用当前游戏程序集验证 API 并生成运行库。
尚需实际游戏内验证 UI 及多人网络行为。

## 鸡舍容量

鸡舍保留原生6/9格布局及巢箱扩容，每批填满一个产出格。
默认生产倍率下，N只鸡每批产4N个鸡蛋、10N根羽毛，每格容量等于该批产量。
家鸡繁殖按养殖槽内的鸡数分档：1～2只每批产2只，3～4只产3只，5～6只产4只；0只不生产。需安装巢箱。
家鸡产出每格容量随分档为2/3/4只，三个产出格总容量为6/9/12只。
繁殖周期保持原生72000 ticks（3个游戏日），育雏灯加速后为1.5个游戏日。
默认饲料倍率下，每只新家鸡消耗15饲料，完整批次消耗30/45/60饲料；鸡舍跑道减半后向上取整，为15/23/30饲料。
缺料或补充未满格时，按实际新增数量收费；沙盒产量、饲料倍率继续生效。
减少养殖鸡数不会删除已存产物；超过新容量的格子暂停补充。鸡蛋、羽毛的现有产量和饲料计算保持不变。
