# 阿帕奇开火反馈（1.27.10）

按用户要求，主武器保留很微弱的真实机身后座力矩，同时限制连发扰动，避免越打越晃。
保留 1.27.8 的主驾火箭和制导导弹刚体力矩，本版增加副驾机炮瞄准时的微弱视觉振动。

## 主武器机身响应

- 只在服务器确认成功发射后触发；主驾火箭轻微抬头并回稳，导弹强度为火箭的 55%。
- 每次持续 0.18 秒，角加速度峰值上限为 0.45 rad/s²。这是刻意弱化的游戏反馈，不是实际火箭后坐力的物理复现。
- 沿发射瞬间机体横轴施加力矩，剔除世界竖直轴分量，不额外添加偏航力矩或平移力。
- 使用一个完整余弦周期的角加速度；开头轻抬，随后反向收住，末段消除回弹角速度。
  按固定步长对角速度解析积分，最后不足一整步也完整结算，因此完整脉冲的净角冲量为零。
  连续时间理想模型的角位移也回零；实际飞控阻尼和离散步长产生的微小余量由现有姿态稳定器收敛。
- 同一载具只有一个物理脉冲槽，执行期间的新发射不叠加、不刷新、不排队；两次开始至少间隔 0.22 秒。
  0.15 秒间隔的火箭齐射会略过部分单发机身反馈，以保持稳定，发射、弹药和伤害照常执行。
- 副驾机炮不能触发、放大或续期主武器力矩，仍保留炮管后坐、火焰和音效。
- 仅当前拥有本机物理控制权的阿帕奇、驾驶员在位、引擎工作、有燃料且离地时启用。
  联机远端副本不重复施力；独立服务器的确认事件路由不依赖本地玩家或渲染器。
  换驾驶员、着陆、熄火、进水、损毁、飞控停用、异常长物理步长等情况取消剩余效果，不延迟补播。
- MD500 不参与武器或开火反馈；不直接改写机身旋转、线速度、输入或瞄准方向。

## 相机和瞄准

普通视角保留极轻的位置反馈，主驾瞄准时不额外抖屏。
副驾瞄准时，确认成功的机炮射击触发沿镜头视线轴的微弱摆动，上限 0.045°，
以约 11 Hz 振动、0.055 秒时间常数衰减，单发实际峰值约 0.03°，停火 0.25 秒后完全归零。
不添加镜头俯仰/偏航，不改变浮动准星输入，也不增加机炮散布或机身力矩。

副驾瞄准振动独立记录最近一次机炮射击时间；每发重启固定脉冲而不相加，火箭/导弹不能刷新它。
显示画面有轻微摆动；计算机炮瞄准、标记等射线时，逆向消除该显示旋转，连同近裁剪面的射线原点一起补偿，
保证偏离屏幕中心的准星也不会把视觉振动传给实际射击方向。边缘目标仍可能有极细微的显示位移。
原生机身/相机跟随仍然存在，此补偿只排除本组件添加的显示反馈，实际观感需要游戏内确认。

每次确认开火只替换相机效果强度，不叠加旧效果。机炮/火箭/导弹系数为 0.65 / 0.40 / 0.22，
主驾强度为副驾的 45%。基础位移系数为 0.0006 米，理论最大局部位移向量小于 0.45 毫米。
以 0.05 秒时间常数衰减，停火 0.25 秒后归零。重复或旧序号不刷新效果。

原生相机更新前移除上帧偏移，更新后呈现当前效果；普通视角的新增位移从瞄准射线原点中扣除。
副驾瞄准的显示旋转同样在原生相机更新前移除，避免参与下一帧原生阻尼。
下车、切座、退出瞄准、菜单、世界清理时恢复相机；其他系统已改变位置或旋转时，不强行写回旧值。
保留原有服务器确认、数据包、弹药、伤害、锁定和制导逻辑。客户端和服务器应使用同一运行库版本。

持续发射的最大角度约为 0.036–0.038 度；停火后余量收敛。
