# M1 副武器模型版

这是模型交付，不是游戏功能更新。没有写入 Mods/ZZ-PZAEC_M1Abrams 的 Resources、配置或 DLL。

## 文件

- `M1Abrams-SecondaryWeapons.blend`：完整可编辑坦克，包含车顶遥控机枪、双联防空导弹架、转轴/枪口挂点、三档 LOD、打包材质及原主炮后坐动画。
- `M1Abrams-SecondaryWeapons.fbx`：完整模型交换文件，保留原主炮动画。
- `M1-SecondaryWeapons-Only.fbx`：仅新增附件及必要父节点，用于后续集成，不含原车体网格。
- `M1-secondary-overview.png`、`M1-secondary-roof.png`、`M1-secondary-launcher.png`、`M1-secondary-elevated.png`：整体、顶部、发射架和抬升姿态离线预览。
- `model-report.json`：实际锚点、网格名称、父子关系、三角面统计和原工程 SHA-256。坐标为中立姿态模型空间，非相对父节点偏移。
- `clearance-report.json`：168 组采样姿态的三角面表面干涉检查，结果 0 组干涉。
- `M1SW-weathered-color.png`：新增武器共用的 2048×2048 迷彩旧化颜色图集，已打包进 Blend 和两个 FBX。
- `export-validation.json`：825 项挂点、层级、LOD、UV、材质、原模型保留及 FBX 重新导入检查，包含导入后颜色贴图连接和像素可用性。

新增 LOD0/1/2 分别为 7200 / 3854 / 1778 三角面。原模型文件 Generated/M1Abrams.blend 保留，用于比较和重建。

## 外观融合修订

新增武器改用接近原车的沙色、灰绿、深灰及棕色迷彩，增加积尘斑驳和细小掉漆，并降低漆面金属感、提高粗糙度。材质在中立姿态下按统一空间尺度生成后烘焙到独立 UV 图集；转动时贴图跟随零件，不依赖 Blender 专用程序节点。

机枪的四根细高支柱改为斜面装甲底座，缩小顶板并保留顶甲固定脚。导弹架的大平板改为两条窄导轨、斜面加强支座与贴顶甲鞍座，加入紧固螺栓和发射筒卡箍。鞍座按前移后的实际位置重新采样顶甲高度。原转轴位置及默认姿态保留。

## 姿态与空间调整

机枪移至左侧支架，俯仰轴在机匣后侧并提高 9 厘米，为低头留出空间。发射架整体向前移 35 厘米避开原天线，俯仰轴移向筒尾以避免抬升时筒尾下压顶甲。默认机枪水平向前，导弹架仰角 20°。

机枪水平轴 RoofMGYaw、俯仰轴 RoofMGPitch；导弹俯仰轴 AAPitch。Blender 中水平轴是局部 Z，仰角为局部 X 的负旋转；后续 Unity 接入应使用模型坐标转换，不能直接照搬 Blender 欧拉轴。

## 验证范围

机枪相对炮塔以 15°水平步长采样，仰角取 −10/0/30/55/80°；导弹架取 15～65°、5°步长；另检查主炮塔八个方向、主炮仰角与后坐组合，以及机枪与自身托架的代表性姿态。支脚与原顶甲的安装接触、轴套与转轴接触为预期结构。

离散表面检查不证明任意连续运动、所有武器组合姿态、舱盖开合或实际游戏碰撞均安全。机枪供弹槽是模型部件，柔性供弹随俯仰的动画尚未制作。新增迷彩与磨损为独立制作的颜色贴图，并非原车贴图的逐像素复制；未新增法线贴图。未连接锁定、弹药、伤害、输入或网络逻辑。

## 重新生成

在 Mods 根目录用本机 Blender 4.5 后台运行 `tools/M1Abrams/build_secondary_model.py`，再运行 `validate_secondary_model.py` 和 `validate_secondary_export.py`。这三个工具只输出本目录；不会更新游戏资源。`-- --no-render` 可跳过建模脚本的预览渲染。

原模型作者和许可沿用 `ZZ-PZAEC_M1Abrams/ATTRIBUTION.md`；新增附件是本次独立建模内容。
