# 自动林场模型替换规格

状态（2026-09-18）：已取得用户提供的源文件，完成模型转换、配置和运行库构建；游戏内显示、碰撞和联网待用户测试。

## 素材与实现

- Old Sawmill (industrial building)，作者 simple and extensive design。
- https://sketchfab.com/3d-models/old-sawmill-industrial-building-39e4cd568ce74dd3a58118d3a5b94471
- 官方公开 API 确认 isDownloadable=true，许可 CC BY 4.0，需署名及标注修改。
- 用户提供 F:/game/old_sawmill_industrial_building.glb 与 F:/game/old-sawmill-industrial-building.zip。原始压缩包中的OBJ引用MTL但未附带MTL，因此采用材质关联完整的GLB。
- 本机未找到Unity编辑器。改用预转换网格文件和运行时prefab，Harmony仅拦截本林场的 BlockShapeModelEntity.getPrefab；放置预览和模型池共用此入口。无需编辑器或额外导入器。
- 移除独立围栏及空地后，等比模型约9.50×3.84格、主体高2.64格；增加10×6底座、外侧操作台、原木和三个可选配件显示。保留10×6×4放置空间。
- 六个网格部分，共23706个双面三角形，两套PBR贴图；模型报告和署名位于模组 Resources/Forestry。
- 主体使用贴合网格的静态碰撞，底座、操作台及配件使用简单碰撞；根触发器提供选择范围，不构成隐形实体墙。

## 已授权设计目标（须拿到源模型后实测）

- 占地宽10、深6，高不超过4格；对应 MultiBlockDim 的 X,Y,Z 为 10,4,6。
- 等比缩放，不扭曲建筑比例；源模型不适配时先报告实际尺寸与必要调整。
- 四向90度旋转，正面外侧操作，第一版内部不可进入。
- 碰撞、选择范围和放置预览须与模型一致。正面操作位置可正常靠近和瞄准。
- 自制模型截图作为物品图标；保留自动林场名称。
- 资源放入 98-AECxProjectZ_Tweaks，保留 yfAutoForestry 和 yfForestryWoodBundle ID。
- 99-AEC_T16_RuntimeFix 继续负责现有累积存储逻辑。
- 不再使用AssetBundle；静态资源边界、拓扑、纹理、图标和配置检查通过后启用运行时模型。原生Unity实例化与游戏内交互尚需实测。

## 已核实的现状

- 当前继承 AutoMinerIron：MultiBlockDim=4,3,3（占地4×3，高3），ModelOffset=0,0.5,0。
- 2500耐久，维修材料为25锻钢、50机械零件、50电子零件。
- 六个输出格、3列2行；普通每格3包/共18包，打包器每格6包/共36包。
- 每包12000木头；容量分别为216000和432000木头。
- CollectorBatchStorage.BatchCount 把每批产量设为3或6，并限制于当前格剩余容量。
- 游戏程序集 TileEntityCollector.fuelCost 实际公式：
  ceil((getFuelCost(type) + AdditionalFuelCost * (count - 1)) / costDivisor)。
- 林场配置 FuelCost=1000、AdditionalFuelCost=0；默认燃料倍率、无Cost配件时，一批1000汽油，产出3/6包；补齐不足一格的批次也按一批扣油。
- 保留上述生产行为，不因模型替换调整经济平衡。旧说明“1000汽油1包”已纠正。
- 原始周期参数 MinConvertTime/MaxConvertTime 均为48000；具体游戏时长和备件加速仍需运行验证，不直接把参数当秒数。
- 保留3个配件：Speed备件、Count资源打包器、Modify警报器。
- 原有 ModTransformEnableNames=2,3,1，DisableNames=,0,。新模型需独立绑定有意义的可选部件，不能直接依赖原挖掘机节点或隐藏主模型。
- 警报器实际关联 CloseEvent=block_autominer_uw：未装警报器时关闭界面有20%概率触发两只工人僵尸事件。保留此规则；不能描述成通用范围驱散。
- 配方保留：改良工作台，3发动机、60锻钢、180锻铁、1四驱车底盘、2电锯。

## 旧存档升级

先退出游戏并备份存档。需要清理旧林场时，在Mods目录执行：

```powershell
pwsh -File tools/Set-ForestryModelMode.ps1 -Mode Legacy
```

启动旧存档，取空汽油、配件和产物并移除旧林场，保存退出，再执行：

```powershell
pwsh -File tools/Set-ForestryModelMode.ps1 -Mode Sawmill
```

重启后重新放置；推荐先在测试存档确认四向布局。切换工具不修改存档，游戏或服务器运行时拒绝切换。
客户端和服务器均须同步98-AECxProjectZ_Tweaks和99-AEC_T16_RuntimeFix。
模型主体的preview.png为离线预览，不含运行时添加的底座、操作台、木堆和配件，不是游戏实测截图。

## 从6×4测试版升级到10×6

如果存档已经放置6×4锯木厂，请退出游戏后使用 Set-ForestryModelMode.ps1 -Mode Compact，再进入存档取空并移除设备，保存退出；使用 -Mode Sawmill 切回10×6后重启并重新放置。Compact只用于旧占地清理，恢复6×4占用并缩放显示，不是独立生产版本。Legacy用于更早的4×3挖掘机版。

新模型等比放大5/3倍；底座、选择范围、操作台位置、原木和配件位置同步调整。操作台和配件本身保持人物尺度。燃料、周期、六个产出格及3/6包容量不变。

## 外观/动画评估后的修复（以本节覆盖前述旧参数）

- 木工台合并明确使用GetComponentsInChildren(true)，并拒绝空输入，修复停用缓存中找不到子网格的问题；远景WoodworkCoarse由此能正常生成。原生配件仍独立显示。
- 锯台改为两块台板，中间留70毫米纵向锯缝；移开锯片包围范围内的滚轮，现为七根滚轮，加入两条承托滑轨。圆锯及其皮带轮同轴Y=1.05，补充轴杆，轴底高于木板顶面。皮带两直段按两轮的外公切线生成。
- 滚轮按送料线速度0.207米/秒及半径0.065米计算负向转速，顶部与木板同向；锯片与同轴皮带轮同速720度/秒，电机皮带轮按0.14/0.11半径比转动，轮缘线速度一致，增加轮面标记以看清旋转。
- 两块1.1米长木料交替送料。在切割平面左侧显示整板，右侧显示两条等长木料和40毫米锯缝，并轻微分开；进料/出料罩遮住显隐边界。每块木料仅在全部离开显示范围后重置，循环不再暴露反向跳位。此为外观流程，不对应额外物品生成或燃料消耗。
- 启动/停机逐步变速，送料与滚轮使用同一速度；只有正在切割且靠近时产生木屑，停发射后现有颗粒自然消散。工作灯16—22米渐减并平滑调光，木屑12—17米渐减；动画使用40/44米回差，可见锯片在远处也继续更新。

- LOD改为按屏幕占比交叉渐隐，保留远处锯台腿和进出料罩；没有更改全局LOD时间或其他模型材质。最终游戏内渐隐仍需确认游戏携带的Standard着色器变体表现。
