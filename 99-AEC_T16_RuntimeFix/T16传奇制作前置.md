# T16 传奇制作前置

Runtime 1.20.2：制作每件 T16 新武器或护甲，都要**实际消耗对应传奇装备**，原有底盘、战术组件、传奇零件、电容、心核及选择箱等材料继续保留。并非只要拥有或解锁过传奇装备。

| T16 装备 | 新增/替换的装备前置 |
| --- | --- |
| 烬火重型手枪 | 传奇地狱枪 ×1 |
| 地平线针刺步枪 | 传奇高斯 ×1 |
| 雷池轻机枪 | 传奇斗牛犬 ×1 |
| 断层震击锤 | 传奇毁灭者 ×1 |
| 壁垒自动霰弹枪 | 传奇抹除者 ×1 |
| 回声连弩 | 传奇螳螂复合弩 ×1 |
| 反攻城脉冲器 | 改进火箭筒 ×1 ＋ 传奇高斯 ×1 |
| 猎隼护甲 | 掠食者传奇护甲，同部位 ×1 |
| 雷暴护甲 | 掠夺者传奇护甲，同部位 ×1 |
| 震岳护甲 | Maus 传奇护甲，同部位 ×1 |
| 守望护甲 | 救援者传奇护甲，同部位 ×1 |

头盔消耗头盔，衣装消耗衣装，手套消耗手套，靴子消耗靴子。主动装置、组件及建筑不属于本次武器/护甲前置调整。

高斯、斗牛犬、毁灭者、抹除者的普通传奇款及该系列各传奇词条款均可用。配方列表中的多个同名配方是**任选一条**，每条只消耗所列的一件传奇武器，不需要收集所有词条版本。螳螂使用 `gunBowT5CompoundCrossbowMantis`。

当前安装内容没有旧传奇火箭筒，反攻城脉冲器采用改进火箭筒 `gunExplosivesT4RocketLauncherImp` 加传奇高斯作为前置。

**不限 Q1–Q6 品质**，但必须是指定传奇物品ID，普通武器即使Q6也不能替代。制作前拆下模组、染色并卸弹；用于制作的传奇装备会被消耗，成品按正常制作品质/耐久规则生成。

当前含 T16 的23件武器/护甲，共46条可选配方（1.21.0加入烬火手枪）。T17–T19已有直接制作配方仍保持原材料，因此该门槛只约束T16制作；已有相邻/跨阶升阶配方和20%融合次数继承规则不变。

代码来源：`Tools/legendary_prerequisites.py`，两个装备生成器会自动写回前置要求。逐件全部材料详见[新物品配方与属性明细](新物品配方与属性明细.md)。
