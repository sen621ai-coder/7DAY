# Boss 原普通书籍池清单

一并从这组抽取中移除的图纸属于武器、护甲、无人机和载具的改装模组制作图纸，不是整车／武器本体图纸，也不是新增 T16–T19 军械蓝图选择箱。蓝图选择箱属于另一项宝箱奖励，此次不变。
