# 装备功能检查与修复

2026-09-05，已安装 Runtime 1.24.0，游戏 V3.2.0 (b10)。在独立测试存档验证，未使用玩家存档。

## 本轮确认并修复的问题

| 范围 | 修复结果 |
| --- | --- |
| 反制干扰弹 T16–T19 | 改为原生手雷：右键拉环、左键投掷，3秒引信；以实际爆点为中心影响8米内敌人，持续3/4/5/6秒。零爆炸伤害，不干扰玩家。 |
| 战场用品与16个主动装置 | 移除误继承的满血禁用条件，修复快捷栏使用后消耗但效果未执行；主动装置仍要求同阶四件套、100共鸣、冷却结束。 |
| 共鸣、校准、干扰与机枪热量 | 修复只发送网络同步包却没有应用本地状态的问题。原生运行中已验证充能、激活、冷却和过热。 |
| T19校准芯片 | 四个主动装置实际分配芯片槽，修复空槽处理。 |
| 战地维修包 | 满血可用，立即修复已穿护甲中磨损最大的一件；无受损护甲不消耗，空护甲栏不报错。 |
| 装甲胶、共鸣注射剂 | 使用前验证修理目标或共鸣条件，失败不消耗。 |
| 供电设备与破甲炮塔 | 缺少供电实体时不再误判为通电；炮塔补齐原生命中破甲状态。 |
| 装甲射击孔 | 四阶均使用原生箭孔碰撞配置，允许子弹和箭通过。 |

反应装甲墙按现有规则工作：单次伤害超过800时，只减免超出部分的18/22/26/30%，每块墙冷却12秒。1400伤害首次触发后为1292/1268/1244/1220，冷却内仍是1400。已补全介绍，没有将它改成常驻减伤。
