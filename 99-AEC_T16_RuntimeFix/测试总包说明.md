# 全新物品测试总包

重启游戏后，按 F1 输入：

```text
giveself itemPZAECTestBundleAll 1 1 true false
```

打开总包获得 T16、T17、T18、T19、通用补给五个分包，再打开需要的分类包。覆盖全部250种新增物品，另附41种关联核心、弹药与补给。武器和护甲每种两件6品质，便于测试融合。每个包最多输出16条物品，打开前预留16个空格，溢出掉落请及时拾取。

测试包仅通过命令或开发者物品栏取得，没有制作配方或正常掉落；不改变逐级升级规则。补给用完可以重复获取总包。

维护：更新新增物品后运行 `python 99-AEC_T16_RuntimeFix/Tools/generate_test_bundle.py`。
