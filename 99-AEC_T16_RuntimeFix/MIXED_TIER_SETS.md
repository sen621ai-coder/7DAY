# 同系列跨阶套装（1.27.3）

Harrier、雷暴 Storm、Tremor、Warden 四个终局护甲系列，T16–T19 跨阶混穿现在累计同系列件数。两件、三件、四件效果均沿用原门槛，不要求同阶。

- 同系列混穿按所穿该系列最低阶提供一套套装效果。例如雷暴 T16 两件 + T17 两件满足四件，使用 T16 套装效果；各单件的护甲、耐久、属性仍为各自等级。
- 不同系列不互凑件数。两件雷暴 + 两件其他系列分别满足各自两件效果，不构成四件雷暴。
- 同系列共鸣计量统一，不因换成更高阶装备而清空。旧存档同系列多个阶级计量取最高值迁移，上限100，不相加；剩余不足三件仍清空。
- 同系列各阶冷却共同限制自动触发，换阶、脱穿不能绕过已有冷却。换阶导致当前套装技能等级变化时，旧主动效果结束，原冷却保留。
- 只允许最低阶的一个套装档位生效，防止多个等级加成同时叠加。原 T19 校准仍要求实际生效的是 T19 四件套。
- 共鸣注射剂按当前同系列三件判定。物品中文说明已补充混穿规则。物品 ID、配方、单件属性不变。

实现：`ArmorFamilySets.cs` 基于原生已装备分组缓存统一计数；原生其他套装分组不改。共鸣和冷却由原服务器逻辑处理，XML 为旧档位残留 Buff 加实时装备条件，并保护换阶时的共享共鸣。

验证：`tools/Test-MixedTierSets.ps1` 穷举四系列各625种空槽/阶级组合并检查旧计量迁移、共鸣保留、跨阶冷却。实际游戏审计 `ConsoleCmdEquipmentUseAudit` 同步改为要求混穿成功。离线结果不代表已完成客户端与专用服务器实机验收；完整重启后生效，联机两端需相同版本。
