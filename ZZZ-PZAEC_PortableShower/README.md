# 腕式便携清洁模块 1.0.1

为当前 Project Z + AEC / 7 Days to Die V3.2 整合环境制作，依赖 Project Z 的卫生系统。

## 制作和使用

- 工作台搜索“腕式便携清洁模块”，内部 ID：`modPZAECWristShower`。
- 护甲制作 50 级解锁；基础制作时间 120 秒。
- 材料：锻钢 10、机械零件 8、电气零件 8、废聚合物 20、短铁管 4、胶带 5。
- 装在手部护甲的普通模组槽。其他部位不能安装，多个模块不会叠加。
- 背包放普通清水（`drinkJarBoiledWater`）。至少有 3 瓶时，空水箱才会消耗 1 瓶补水；始终保留最后 2 瓶饮用水。不取快捷栏、附近箱子或载具内物品。
- 一瓶水提供 60 秒有效喷淋时间。水量储存在玩家持久 CVar `$PZAECShowerWaterSeconds`，拆装不重置，转交模块不会把原玩家的水量赠送给别人。
- 30 秒没有战斗/攻击事件后开始清洁。主副手操作采用保守判定，工具使用及瞄准也会重新计时。受击、爆炸攻击、载具攻击、进入战斗同样重新计时。登录和复活至少等待 30 秒。
- 奔跑、游泳、乘车、死亡、卸下手套/模块、身体已干净、使用原有沐浴设施时暂停，不消耗水。攻击事件立即撤下清洁状态；移动等状态在下一次每秒检查时撤下。
- 每秒补充卫生上限的 1/300。忽略自然变脏时，5 分钟有效喷淋可恢复一整条卫生值，消耗约 5 瓶。自然脏污持续产生时实际时间会稍长。最后不足一秒的清洁按实际有效时长扣水。
- 仅实际消耗新的一瓶清水时显示“清洁模块：已使用1瓶清水”，持续4秒。持续清洁、暂停恢复及缺水不再弹出提醒，内部清洁/缺水状态隐藏。图标复用原版净水模组并着色。清洁时不显示水流或喷雾视觉效果，保留轻微喷淋声，仅本机可听，不产生 AI 噪声或热度；暂停自动关闭。本版没有独立腕部三维模型或抬手动作。

只恢复 `$HygieneStatus`，不赋予浴缸的压力/疲劳恢复，不治疗感染、伤口、辐射病，不改变饮水属性。

## 安装与验证

完整目录放入 Mods，退出并重启客户端。联机双方及服务器安装同一版本。背包和卫生处理在拥有该角色的客户端执行，专用服务器和远端角色副本不重复扣水，采用游戏现有角色数据同步与存档机制。

构建：`pwsh -NoProfile -File tools/PortableShower/Build.ps1`

验证：`pwsh -NoProfile -File tools/PortableShower/Test-Runtime.ps1`；使用带 lxml 的 Python 执行 `tools/PortableShower/Test-Config.py`。

已做本地编译、真实源码的行为夹具测试、原生事件/动作工厂检查，以及全部已安装 XML 合并后的配方/解锁/图标校验。尚未完成游戏内和联机实测；尤其需验证背包扣水同步、退出重进后的水量、实际卫生增长及手套装卸。
