  （`GetPlayerDamagePercent → 0`）；径向爆炸直接命中乘员实体时 →10%

  舱内规则——辐射对抗留给终局装备。
- **装甲模组标签**：放置物 Tags 补齐 `varmor,vengine,vfuel,vlight,vstorage,

  MaxHealth 加成与百分比减伤独立叠加。
- **战地维修**：禁用原版货箱/物品栏维修（附中文提示）。维修包放货箱，
  停车后在车外 8 米内对准机甲**按住 F 8 秒**（`pzMechaRepairKey` 可配置）：
