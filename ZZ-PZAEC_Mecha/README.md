## 0.8.0 初号机（完全体）

新增独立实体 `vehicleCombatRobotComplete`、放置物品 `vehicleCombatRobotCompletePlaceable`、专属骨架 `vehicleCombatRobotCompleteChassis`，青春版保持原有 ID 与数值。两款使用统一远程驾驶体系和通用弹药，不恢复近战模式；新模型自带刀剑仅为外观。

|---|---:|---:|
| 机体耐久 | 2,000,000 | 3,000,000 |
| 储油量 | 300 L | 450 L |
| 光束直击 | 60,000 | 90,000 |
| 光束溅射 | 45,000 | 67,500 |

血量、攻击伤害和储油量为本次 +50% 的范围；速度、射速、冷却、射程、弹药消耗和装甲减伤比例保持一致。光束直击方块伤害 22.5、导弹方块伤害 60。超过原生 16 位单次伤害安全范围的攻击拆分为安全伤害事件，弹药、热量和自定义发射效果仍按一发结算；对具有单次伤害上限的目标，拆分后的实际扣血可能不同于单次大额命中。

完全体在载具制作技能 100 解锁，在 AEC 终装工作台制作。专属骨架及普通装配材料、制作时间按约 1.5 倍配置（整数向上取整，发动机/电池各一，骨架一）；青春版及弹药配方不变。

模型：Samurai Style Gundam Mecha，作者 lawlietrecluze，CC-BY-4.0；原始文件与署名存于 Resources。原模型 200 万三角形经保留 UV 的简化生成约 20.7 万面版本，独立程序化蒙皮绑定到现有 IK。原模型没有骨骼或动画，关节权重是本模组新增的近似绑定，需要通过实机观察继续打磨装甲关节变形。构建工具 `tools/Mecha/Prepare-Complete.py` 使用 numpy/Pillow/pymeshlab，仅生成资产时需要，游戏不依赖 Python。

回退备份：`.local-tests/Mecha-0.7.3-before-complete/ZZ-PZAEC_Mecha`。联机各端需统一更新到 0.8.0。

验证：正式 DLL 已重建，63 项离线检查、两款模型资源校验及 49 项游戏引擎隔离检查通过。实测完全体耐久 300 万、17 个蒙皮网格、207,192 三角形，初始姿态误差约 0.0000013 米；关节移动能带动蒙皮，原生两次安全伤害调用合计扣血 90,000。报告与引擎预览位于 `.local-tests/Mecha-0.8.0-review/`。该检查不替代真实玩家驾驶、全流程实弹命中、复杂地形及多人验收；新模型关节权重仍需实机观察打磨。

## 0.6.8 停火纪律修复（“一直枪声”根因）

用户审查定位的确定性漏洞：`Aim`（瞄准保活消息，空闲时 10Hz 发送）与
`Fire` 共用 `Aiming` 状态——服务器把纯瞄准当成扳机按住，**静止不按键也
每 0.5s 开一炮 turret_fire**，即持续枪声。

- **瞄准/扳机分离**：新增 `TriggerHeld`/`MissileTrigger`——只有
  `Fire`/`MissileFire` 扳扳机；`Aim`/`MissileAim` 仅维持瞄准会话与锁定累积。
- **Stop/失效全清**：松手、下车、开界面、操作员失效同时清除扳机、瞄准、
  锁定与有效期——任何路径都不能恢复开火。
- **旧消息彻底丢弃**：过期序号不再刷新会话有效期（重放无法延长异常状态）；
  任意**新序号**消息（含 Aim）续期瞄准会话（锁定可正常攒满 2 秒）。
- **BeamEvent 按（载具，序号）去重**（重放不双响）；近战挥刀改独立音效
  `electric_fence_impact`，光束保持 `turret_fire`。
- **开火审计日志**：每 10 秒最多一条 `[Mecha] beam v=… ammo=… heat=…`——
  下次枪声异常时可直接对照日志中扣弹频率定源。

## 0.6.7 矩阵数学修正（审查复核）

- **TRS 旋转镜像统一**：TRS 路径的四元数镜像从 `(-x,y,z,w)` 改为正确的
  `(x,-y,-z,w)`（X 镜像的旋转共轭）；当前模型全部走 matrix 路径不触发，
  属正确性兜底。
- **负缩放分解符号保留**：旋转列归一化改用带符号缩放（`scale.x` 含符号），
  镜像矩阵分解不再丢符号；本 GLB 无负行列式矩阵，属正确性兜底。
- **参考渲染器索引修正**：顶点变换从列序混合改为与内部行主序一致
  （x'=row0·p、y'=row1·p、z'=row2·p）——参考图现在可用于验收对照。
  修正后的渲染显示模型真实姿态：半蹲马步战斗姿势（双臂横展、双腿分立、
  躯干前倾）——此前看到的"残缺/翻倒"即 matrix 缺失的堆叠假象。
- **真数值测试**（替代源码关键字检查）：父子矩阵组合一致性与镜像恒等式
  `S*(M*S*p)==(S*M*S)*p` 逐分量验证；`tools/Mecha/Test-ModelTransforms.ps1`
  共 9 项全过。

## 0.6.6 模型导入修复（matrix 节点变换）

用户源码对照发现的真根因：该 GLB 有 **156 个节点用 `matrix` 字段**保存变换，
而此前建树代码只读 translation/rotation/scale——件全部按单位矩阵堆在原点，
这就是"残缺/散件/姿态怪异"的根因。

- **GLB 节点 matrix 读取**：列主序 16 值 → Unity 局部 TRS 分解
  （列向量模长取缩放、行列式<0 折叠到负 X、正交化列转四元数、
  重建残差 >0.01 时按节点名警告）；坐标镜像统一 `S·M·S`（X 镜像），
  与顶点镜像一致。
- **保留完整包装层级**：Sketchfab_model/.fbx/RootNode 不再跳过（它们携带
  方向/缩放变换）；展示地板改按**材质**排除（不再删父节点）。
- **多 primitive**：BuildNode 不再只取第一个。
- 贴地修正与锚点不变；骨架重组/步行 IK/登机演出维持关闭（`RigRebuildEnabled/
  GaitIkEnabled/BoardingEnabled = false`）。
- 新增 `tools/Mecha/Test-ModelTransforms.ps1`：matrix 节点计数/有限性、
  镜像约定、件数 153、包围盒合理性；修复 `Render-Model.ps1` 同 matrix bug。
- 离线验证：6/6 变换断言 + 66/66 全套断言。
