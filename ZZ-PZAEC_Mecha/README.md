# PZAEC Combat Robot 战斗机甲 0.6.0

## 0.6.0 登机/下机仪式演出（四段完整版）

拦截原生登机/下机（`EntityVehicle::EnterVehicle` / `DetachEntity` prefix），
播放关节动画演出时间线，多人通过事件包（kind 8）时间戳同步、各端确定性
本地采样（与放置动画同架构）：

- **登机 4.2s 四段**：展开（微蹲+双臂外展+掌心光圈，1.2s）→ 迎接（右臂下探
  指向登机者，0.7s）→ 拉升（放行真正登机+玩家隐藏+**相机从玩家眼位飞升至
  头部 FPV**，0.8s）→ 合拢（双臂内收+直立+胸口光缝闪+"战斗系统联机"打字机，
  1.5s）。电影黑边淡入淡出。
- **下机对称 2.2s**：展开腾位 → 相机俯冲至地面落点 → 放行 detach → 机甲站起。
- **跳过**：演出中按 E 或移动键立即完成（op 13 意图，服务器幂等）。
- **演出 gate**：期间武器/模式/维修全部服务器拒绝；悬浮/践踏因无驾驶员天然冻结；
  Gait 让权给演出姿态驱动（Pose 关键帧插值：膝/躯干/双臂 roll+pitch）。
- **降级开关**：`Rules.BoardingEnabled = false` 一行退回"登机不变、仅演出
  后半"的稳妥两段版（网络时序异常时兜底）。
- 拦截放行用 passThrough 防递归；远程观众由 BoardEvent 回放本地演出。

## 0.5.0 机体替换：双足 Combat Robot + 运行时骨骼重建 + 双足 IK 行走

完全替换三足 Buster Drone（旧 GLB/锚点/步态已移除；载具名
`vehicleBusterDrone` → **`vehicleCombatRobot`**，注意旧存档中已放置的
三足实体会失效消失）。全部战斗/防护/机动系统（v0.1–v0.4）原样继承。

- **新模型**：Combat Robot by ILUSHANDRO（CC-BY-4.0），84.7MB "静态雕塑"
  导出——154 网格件平铺无关节、零动画。运行时管线：
  15 张 4K 贴图 → 1024² 外部 PNG（复用预处理脚本）；`Floor` 展示地板剔除；
  按包围盒自动缩放至 **3.2m** 身高。
- **运行时骨骼重建**（`RebuildBipedRig`）：154 个网格件按世界坐标启发式
  （左右分侧 + 髋/膝高度分段 + `_Hands_0/_Torse_0/_Legs_0` 材质组）重新
  挂入程序化关节链 `Hip→Knee`（双腿）与 `Shoulder`（双臂），
  `worldPositionStays` 保持站姿。
- **双足 IK 行走**（`Gait` 重写）：
  - 迈步循环：落足点预测（速度预描 + 阈值触发）、双腿交替、
    抛物线抬脚 0.4m、落足射线取真实地面/台阶高度（上下坡贴地）；
  - 两骨解析 IK：髋-膝-脚平面三角解算（余弦定理），膝单向后弯；
  - 动态感：重心左右摆 8cm、躯干随速度前倾（≤8°）、手臂反相摆动 ±15°；
  - 四态：站立呼吸 / 行走 / 悬浮收腿后摆（Q 悬浮时） / 放置蹲起
    （程序化 2.5s 站起替代旧 25s GLB 动画）。
- **锚点重映射**：掌心=光束炮口（原眼部）+ **双手持能量刃**（原肩挂）、
  头部=FPV 相机、背包=导弹发射巢。
- 双足窄轮距（±0.85/±1.5m）+ 腹部滑块保留；其余（护甲 200 万/15% 减伤/
  悬浮/蓄力跳/践踏/维修/HUD）与 0.4.0 一致。
- 待游戏内调参：MountRotation 朝向、IK 膝弯符号（HipSign/KneeSign）、
  刃挂点角度、步幅/步频手感。

## 0.4.0 全地形机动系统（弹坑免疫）+ 践踏

针对血月战场弹坑地形的瘫痪风险（台阶卡轮 / 坑脊托底 / 连环深坑）重做机动：

- **轮系强化**：轮径 0.4→0.5、悬挂 0.3→0.4、弹簧 18→22 万（M1 坦克实测档）；
  涡轮 11→13.5 m/s（对齐主战坦克）、unstickForce 1→2、upForce 1→1.5。
- **腹部滑块**：底盘中央低摩擦（0.05）碰撞条——坑脊托底时滑过而非架死四轮悬空。
- **悬浮巡航（Q 单击切换，无冷却）**：PD 控制悬停于支撑面上方 1.2m（头顶 3m 限高），
  W/S 推进 + A/D 偏航力矩（轮离地后原生转向失效由力矩接管）、水平软限速 6 m/s、
  悬浮中按住 C 主动下降；耗油 0.5L/s（300L 油箱 ≈ 10 分钟）；落水/倾斜>70°/熄火/油尽自动关闭。
  弹坑区直接飘过——"无人机改步行机"人设的短程悬浮。
- **蓄力跳（空格按住 0.5s 蓄力→松开）**：跳高 2.5m（轻点）~5m（满蓄，VelocityChange 9.9 m/s），
  冷却 4s（起跳后计）。HUD 蓄力条与近战重斩同套视觉语言。
- **践踏（服务器权威）**：
  - 移动碾压：轮触地 + 水平速度 ≥2 m/s 时每 0.35s 判定足下 2.2m 半径敌对实体，
    12000 钝击/次（同一实体 0.5s 间隔；悬浮中天然不触发；静止不触发）。
  - 空降砸踏：滞空 ≥0.5s 后落地瞬间触发原生爆炸——30000 实体伤 @3.5m、击退 120、
    0 方块伤、1s 限流。悬浮巡航降落实战价值："飞到 Boss 头上砸下来"。
  - 物理/伤害分工：驾驶员客户端（物理权威）检测条件发意图包（op 11/12），
    服务器独立枚举结算（限流防伪造）。
- 数值定位：T16 小怪 16 万血被路过碾压 3.5s 死、T19 小怪 54 万 16s——零操作零弹药的
  "顺带碾压"，主输出仍是光束/横扫。

## 0.3.0 血月主战化 + 远程/近战双模式能量刃

定位从支援载具改为**血月主战载具**（铁砧+收割机），按 T16–T19 威胁基线全轴重调：

- **伤害**（每个伤害事件仍 ≤65535，不依赖 Damage32）：
  - 光束 45000 → **60000** 直击 + 新增 **45000 溅射 @3m**（0 方块伤害，基地内安全开火）：
    主目标 105K/发 ×2/s = **210K DPS**；T16 小怪（16 万血）≈2 发、T19 小怪（54 万）≈5 发（~2.5s）。
  - 热量放宽：8/发、散热 20/s（平衡 2.5 发/s > 射速 2 发/s）→ **无限持续射击**，无强制停机。
  - 导弹 60000/8s 冷却不变（贴网络上限）。
- **护甲**：耐久 80 万 → **200 万**（M1 坦克 T17–T18 档）；减伤通道 25/40% → **15%（战斗）/30%（爆炸）**，
  单击上限 15% → **10%**（20 万/击）。有效承伤 **~1333 万**：T19 Boss 减伤后 3,848/拍 ≈ 硬抗 8.7 分钟；
  血月 8 只围攻整夜 ≈ 损耗 60 万，多夜免修。乘员保护不变（封闭舱档）。
- **持续作战**：
  - **紧急维修（R 键，驾驶中）**：扣 1 原版维修包回 15%（30 万），60s 冷却——血月中唯一恢复手段。
  - 能量电池堆叠 100 → **200**、配方产量 10 → **20**；整夜 ~50% 占空比约需 5 组。
- **双模式能量刃（X 键切换）**：
  - 远程模式（默认）：左键光束、G 导弹（两模式均可用）、右键瞄准镜。
  - **近战模式**：双刃自肩部面板（Drone_UPanel_L/R）程序化展开（收纳↔展开 0.3s+音效+青色自发光+拖尾）；
    左键**点按**=360° 横扫（4.5m、45000 伤、击退 80、冷却 3s）；
    左键**按住 0.5s 蓄力**（刃体发光渐强）松开=前方 120° 重斩（5.5m、60000 伤、击退 140、冷却 4s）。
  - 服务器权威：模式为服务器状态（op 8 切换/9 横扫/10 重斩），近战模式下光束 op 直接拒绝；
    挥击服务端枚举敌对实体+距离/角度+射线遮挡校验；击退为 0 伤害高 BlastPower 冲击波（不拆方块）。
  - 下机/死亡自动收刃重置远程模式。共享冷却槽防刷。
- Boss 仍由地面终局装备输出（T19 Boss 260M ≈ 21 分钟）：机甲扛线+清场+应急维修。

## 0.2.1 武器数值校准（对齐 T16–T19 清怪吞吐）

按威胁基线核算（持续光束 DPS 由 ~30K 提至 ~44–52K）：

- 光束实体伤害 30000 → **45000**：T19 小怪（54 万血）击杀 15–18s → **~11s**，
  T16 小怪（16 万血）→ **~3.5s**；电属性依旧绕过 Boss 35–65 物理抗性，
  数值仍低于 65535 网络上限（不依赖 Damage32 补丁）。
- 导弹冷却 10s → **8s**（与阿帕奇制导节奏对齐，60K/8s ≈ 7.5K DPS）；
  导弹伤害 60000 保持——已贴 16 位网络上限。
- Boss 定位不变：载具为地面火力支援（T16 Boss 4000 万血 ≈ 15 分钟级），
  与阿帕奇“Boss 仍需地面配合”同梯队。

## 0.2.0 防护三件套（乘员保护 / 装甲模组 / 战地维修）

按 T16–T19 实测威胁基线（Boss 近战单击最高 ~25,650、AoE 峰值 ~8,100，
来源 `98-AECxProjectZ_Tweaks` 数值层）补强机体生存能力：

- **壳体减伤**（`MechaArmor.cs`，ApacheArmor 响应一次性缩减模式）：战斗伤害
  →25%、爆炸内 →40%、碰撞/磨损 →50%，单击上限 15% 最大耐久（12 万）。
  防爆斩杀线与 99- ApacheArmor、ZZ-PZAEC_M1Abrams 通过 `HarmonyAfter`
  哨兵合成共存（三者同装时逐级包装，互不覆盖）。
  核算：T19 Boss 近战 25,650 → 6,413（80 万耐久约 125 拍）；T16 近战约 312 拍。
- **乘员保护**（M1 封闭舱档）：壳体受击对驾驶员的百分比传导归零
  （`GetPlayerDamagePercent → 0`）；径向爆炸直接命中乘员实体时 →10%
  （爆炸 →20%），单击上限 20% 玩家最大生命。环境/状态 DoT（辐射等）保持原生
  舱内规则——辐射对抗留给终局装备。
- **装甲模组标签**：放置物 Tags 补齐 `varmor,vengine,vfuel,vlight,vstorage,
  canHaveCosmetic`（阿帕奇 0.7.3 同款集合）——可装装甲/引擎/节油/副油箱/
  越野灯/储物（4 槽）；不开放座位扩展（单座）与推土铲。原生装甲模组的
  MaxHealth 加成与百分比减伤独立叠加。
- **战地维修**：禁用原版货箱/物品栏维修（附中文提示）。维修包放货箱，
  停车后在车外 8 米内对准机甲**按住 F 8 秒**（`pzMechaRepairKey` 可配置）：
  服务器权威通道（序列号租约防重放），要求脱战 10 秒、无人驾驶、机体静止、
  尊重锁定与所有权；完成扣 1 个原版维修包并满血。
- **战损反馈**：HUD 新增机体完整度条（受创 10 秒内变红并提示冷却）、
  车外瞄准机甲显示状态面板与维修进度条；StatusEvent 扩展 HP 百分比、
  受创标志与维修进度（`b.y/b.z` + flags bit32）。

全部服务器权威；Intent 包新增 op 5/6（Repair/RepairStop），零新增包类型。

## 0.1.0 初版

载人三足战斗步行机。机体模型 `Resources/buster_drone.glb`（Buster Drone by
LaVADraGoN, CC-BY-4.0）由 C# 在运行时直接解析 glTF 2.0 二进制并构建网格，
不依赖 Unity 编辑器或 .unity3d 资源包；4K 内嵌贴图经
`tools/Mecha/Prepare-Textures.ps1` 降采样为 1024² 外部 PNG，加载器优先读取。

- 驾驶：单座，登机后本地玩家模型隐藏（封闭机体），相机进入眼部第一视角，
  鼠标独立累积偏航/俯仰，右键瞄准镜（Z 键 2×/4× 变倍），机体姿态不影响瞄准。
- 放置展开：新放置的机甲播放 GLB 自带 25 秒 `Start_Liftoff` 全机展开动画
  （关键帧在运行时采样；登机或超时自动快进到作战姿态，世界加载恢复的旧机体不播放）。
- 步行：三条 7 段关节腿按水平速度驱动程序化步态（相位差 120°），双涡轮持续旋转。
- 武器（服务器权威，弹药取自载具货箱）：
  - 眼部光束炮（左键）：0.5s 间隔、热量/过热、射程 250m、电属性伤害 30000，
    服务器校验射界（偏航 ±90°、俯仰 -85°~25°）与炮口遮挡。
  - 肩部制导导弹（G 键）：对准活僵尸 2 秒锁定后每按一次发射一枚，
    45°/s 转向追踪、6s 寿命、实体伤害 60000（不依赖 99- 的 Damage32 联机补丁，
    全部数值低于 65535 网络上限）、10 秒装填。
- 推进跳跃：驾驶员按住空格获得持续升力（1.6s 燃烧上限，5s 冷却），原生悬挂与阻力保留。
- HUD：中心准星、光束温度条、弹药计数、锁定进度、导弹装填与推进器状态（中文）。
- 网络：客户端仅发送意图射线；弹药、射界、追踪与伤害全部在服务器结算，
  事件包驱动各客户端的光束曳光与导弹视觉。

配方走 AEC 终局载具装配台（依赖 `07-AEC-Vehicles-NoMicrocraft`），
底盘 + 小引擎 + 蓄电池 + 传奇零件；弹药在普通工作台制作，
`craftingVehicles` 100 级解锁（与阿帕奇、M1 同梯队）。

构建：`pwsh -File tools/Mecha/Build.ps1`（Roslyn 就地编译 Source/*.cs 到
`PZAEC.Mecha.dll`，改动源码后需重新构建并随源码一并提交 DLL 与 ModInfo 版本）。

待游戏内验收：模型朝向/缩放（`Rules.MountRotation/MountScale`）、步态关节轴
（`Gait` 的摆动轴）、眼部相机遮挡、展开动画观感、联机伤害与锁定同步。
