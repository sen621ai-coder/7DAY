Logic Circuit Gates / 逻辑门电路 1.2.0
========================================

包含：与门、或门、非门、异或门。

接线规则
--------
1. 接到逻辑门的第一条线是主电源输入，显示为黄色。
2. 此后接入的线是逻辑信号输入，最多 4 条，显示为蓝色。
3. 从逻辑门接出的线是输出：逻辑成立时为绿色，不成立时为红色。
4. 再次把同一个信号源接到同一个逻辑门，会移除该信号输入。
5. 若要更换主电源，先按游戏原有方式断开主电源线，再接入新的第一条线。

功率规则
--------
逻辑门自身耗电为 0W，但不会创造电力。逻辑成立时，它只把主电源线路的剩余功率
继续传给下游设备；逻辑不成立时，输出为 0W。信号线只传递开/关状态，不叠加瓦数。

与门测试示例
------------
  电池组/发电机 --------> 与门（第一条线：主电源）
  正常电源 -> 开关 A ---> 与门（信号输入）
  正常电源 -> 开关 B ---> 与门（信号输入）
  与门 -----------------> 灯

开关 A、B 需要按游戏原有规则获得电力。两个开关都开启时灯亮；任意一个关闭时灯灭。

逻辑规则
--------
- 与门：至少连接 2 路信号，并且全部开启时输出。
- 或门：任意一路信号开启时输出。
- 非门：没有信号开启时输出。
- 异或门：开启的信号数量为奇数时输出。

获取和制作
----------
配方在工作台中始终解锁。也可以在控制台使用：
  giveitem logicGateAND 1
  giveitem logicGateOR 1
  giveitem logicGateNOT 1
  giveitem logicGateXOR 1

安装要求
--------
- 单机：完整退出游戏后安装/更新，再重新启动。
- 联机：服务器和所有客户端都必须安装相同版本。
- 需要关闭 EAC。
