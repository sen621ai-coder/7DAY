# 基地无线监控系统 1.0.3

工作台可制作“基地监控摄像头”和“4×3基地监控屏”。摄像头耗电5W，大屏耗电30W；两端各自接电，不需要视频线，也不要求使用同一电网。

在门口放置摄像头并通过原生“选项”调整角度。在地下室留出宽4格、高3格的完整墙面放置监控屏。长按大屏选择“设置监控”，在列表中选择128格内摄像头并绑定到1～4号频道。绑定后可手动选频道或开启5秒轮巡。摄像头断电时保留绑定，恢复供电后自动恢复画面。

1.0.3新增“目标红框”开关：长按大屏进入“设置监控”，点击“目标红框：关闭”即可开启，再点关闭。默认关闭，每块屏幕独立保存到世界存档并同步给其他玩家，只有屏幕放置者或管理员可修改。同一摄像头可在一块屏上显示红框、另一块屏上关闭，仍共享同一路视频。

红框标记镜头48格内活着的丧尸和动物（含中立动物）；不标记玩家、普通人形NPC和尸体，也不判断动物是否正在攻击。依赖实体类型/动物标志，不是自动识别任意模组的阵营。只有射线从镜头直接碰到目标躯干或头部才标记，墙体/关闭的门会阻挡；部分露出头部可框出整个人形外接范围。极近、跨越镜头近裁剪面或不足4像素的目标保守不显示。

每次成功视频帧最多检查24个近处候选、发出32条遮挡射线、显示16个红框；红框与该帧一同保留/失效，不读取远处未加载实体。任一可见屏幕开启时，同一镜头只检测一次；全部关闭时不执行检测。关闭某块屏幕的开关不会影响其他屏幕。联机服务器及客户端必须统一更新到1.0.3，消息格式已增加红框状态。

每客户端最多同时渲染4路不同镜头，同一镜头被多块屏幕使用时共享画面，只占一路。靠近屏面8格内开始观看，离开10格停止；只为玩家主相机前方、视野内屏幕更新，移出视野200毫秒后停绘。隔墙遮挡尚不作为停绘条件。

1～2路目标各10Hz；3～4路时，视野中心正在看的镜头目标10Hz、其余各5Hz；没有明确焦点时各6Hz。768×576、512×384、384×288按屏面在玩家视野中的像素大小自动选择，带切换回差与冷却。帧率是目标值，受游戏实际帧率和绘制成本限制。

首帧完成前显示连接中；画面超过300毫秒未更新提示延迟，超过500毫秒停止显示旧画面。无引用相机保留最多5秒便于转身恢复，最多缓存4路。专用服务器只同步设备和绑定状态，不渲染视频。

大屏菜单新增本机选项“自动保底（试验）”，默认关闭；开启后持续低帧率会先降低分辨率，再将刷新目标降到每路5Hz，稳定10秒后逐档恢复。关闭此选项使用固定调度与投影画质策略。这些是本机会话设置，不改变其他玩家配置。

验收时勾选“记录性能”，退出菜单正常观看60秒，再打开菜单点击“导出记录”。路径写入游戏日志，文件位于当前游戏使用的数据目录所解析的世界存档路径下的SurveillanceDiagnostics。汇总CSV包含各路更新数、帧龄、资源数及CPU调用耗时；配套events.csv逐帧记录游戏帧时间、成功/失败绘制、首帧等待，用于统计p95。事件缓冲最多65536条，超出保留最近记录并标记覆盖数量。记录默认关闭，数据在内存聚合后导出；不包含GPU时间或真实显示器端到端延迟，需客户端录屏/分析工具另外验证。

当前限制：摄像头所在客户端区域必须已经加载；未加载时大屏会显示状态。夜间画面使用门口真实照明，不提供夜视。房主和所有加入者必须安装相同版本并完整重启游戏。
