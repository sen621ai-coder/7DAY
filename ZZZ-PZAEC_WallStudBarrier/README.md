# 墙钉拒止 1.2.1

适配当前 V3.2。所有材质的完整 `wallStud` 形状自动生效，已有墙钉无需重放。不包含 `wallStudBroken` 破损形状。

- 完整墙钉本体取消怪物绝对免伤：怪物和环境经普通方块伤害入口造成的正伤害降低80%，实际承受20%。正整数伤害向上取整，最少1点；0伤害和负数维修量不变。
- 禁止主动选择墙钉本体作为拆墙任务、攻击动作和破坏区域目标；AI目标拒止与实际伤害减免分开，意外命中仍按20%结算。攻击指向被墙钉格遮挡的普通后墙时，仍在AI准入及最终伤害入口完全拦截。
- 原生爆炸有独立结算：墙钉剩余爆炸伤害在原材质抗爆基础上再乘0.2，沿用原生爆炸的整数舍入、距离衰减、领地保护和摧毁流程。玩家、怪物、无来源爆炸均适用，不改变爆炸对实体的伤害。
- 拒止按墙钉所在整格计算，视觉空隙不允许拆墙攻击穿过；检查攻击者到目标方块的连线，不提供附近全方位免伤光环。
- 保留原有形状、移动碰撞和玩家拆除行为，不扩大实体碰撞，不产生击退、伤害或传送。未覆盖的侧面、顶部和其他通路仍可被利用。
- 在原生 A* 搜索提交到工作线程之前，为敌对生物安装独立通行过滤器：墙钉占据的身体空间不可通行，不能被当作“拆掉就能走”的捷径。有可达绕路时，由原生搜索选其他路线；其他地形、门和普通墙的原生代价保持不变。
- 路径平滑也检查墙钉，防止绕路被缩短成穿墙钉的直线。保留后墙攻击/伤害拦截作为旧目标和特殊攻击的兜底，不再只依赖扣血拦截。
- 1.1.1 修正贴墙发呆：实际寻路起点允许离开墙钉接触区，其他节点仍禁止进入；旧碰墙记录只约束拆墙动作，不阻止普通实体攻击。
- 服务端检测墙钉附近持续至少3秒几乎未移动、且仍有远处追击目标的敌人，清除旧拆墙/碰撞状态并主动重新寻路；短暂退出破坏区域任务以让追击继续。重试间隔逐步增加至12秒并错峰，已有寻路计算、近距离交战、客户端副本和其他位置的拥堵不触发。
- 通行过滤考虑体高、体宽和浮动原点，只影响敌对生物，不修改全局图节点。每次搜索独立缓存通行结果，下次搜索重新读取方块；拆除、放置墙钉后的当前旧路径可能需要原生重新寻路周期才更新。完全封闭或绕路超出原生搜索范围时仍可能滞留，不会强行穿过墙钉。
- 寻路与后墙攻击拦截仅针对实体定义中 `bIsEnemyEntity` 为真的非玩家生物。墙钉本体减伤适用于非玩家来源以及无攻击详情的环境伤害；有原生攻击详情的玩家直接工具/武器伤害不变，正常拆除不受影响。
- 后墙的完全保护针对穿过墙钉的怪物方块攻击；原生爆炸保留自身遮挡规则，不新增后墙爆炸免疫。结构失稳坍塌、管理员删除、其他模组直接替换方块不属于扣血减伤，不能保证保留墙钉。

本模组不设置路线总长度上限。当前原生基础导航网格为76×76格、每格1米；导航区域随活动位置移动/合并，曲折路线长度不等于网格边长。超出有效导航覆盖或无法形成完整路径时，不能保证找到现实中存在的远距离绕路；此时仍不会主动拆墙钉，保留限频恢复机制。源码中的128米仅是直线遮挡扫描上限，不是寻路长度。

完整退出并重启游戏；联机服务端与客户端均安装本目录。没有存档数据迁移；移除此模组会恢复原版拆墙规则。

已通过140项真实源码伤害/AI/恢复行为检查、33项导航场景检查、原生 Hook 签名与爆炸入口核对，并用本机游戏程序集编译。导航场景在原生接口夹具上运行，不能替代游戏引擎实测；尚未进行实际尸潮、特殊 Boss 技能或多人游戏验证。
